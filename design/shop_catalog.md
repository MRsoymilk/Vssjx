# 原包商城与完整物品接入

[返回设计索引](README.md) · [数据工具](../docs/data-tools.md) · [装备制作流程](ai-equipment-art.md)

性质：**当前商城规则与原包证据说明**。当前目录共 394 项：208 个原包图标对应的重建物品、6 个兼容物品，以及三系列各 60 件新装备。新增系列见 [骨甲幽光](boneglow-equipment.md)、[冥林异装](gravebloom-equipment.md) 和 [初号机参考套装](eva01-equipment.md)，不计入原包恢复数量。

## 资源与重建边界

原版证据见 `analysis/recovery/shop/native_shop.json`：`shop.str` 的商城标题和热卖、奇珍、炼制、仙丹页签，`gameonline.ext` 的两列商品、28×32 图标、112×38 单元格、五行可见区和调色板。游戏界面沿用该结构，增加分类、数量、装备及试穿操作。

`client/assets/data/shop-v2.json` 覆盖 `original_items.json` 的全部 208 个原包图标（56 兵器、81 装备、71 其他），另保留旧存档的六个物品 ID。支持原版十个装备位置；药品分气血、灵力及双恢复，另分药材、宝石、配方、材料、特殊物品。材料目前可买入、堆叠及丢弃，尚无炼制配方执行功能。

**原服务器物品表尚未恢复。** 分类、显示名、价格和属性均为明确标注的重建规则。兵器部件依据图形核对；衣服、头饰使用同序的原包人物部件，此对应可调整，不能将试穿结果视为原版物品与外观映射的证据。原始记录中的未知字段仍保留为空。

`hero-parts.json` 保留六个角色 ANI 的原始图层、坐标、旋转及播放数据。299 张部件图集保存 956 个原始帧；运行时组合武器、衣服和头饰，缓存最近六套合成资源，避免预生成全部组合。原版待机、行走、攻击、施法及受击序列与战斗锚点继续复用。

## 商城分类样式与布局

商城分类控件及标签／商品区排列定义在 `client/scenes/ui/shop_panel.tscn`，使用纵向与横向容器按控件实际最小尺寸排列，保留5像素行距，避免字体最小高度使固定坐标区域重叠。分类按钮与弹出列表共用 `shop_category_theme.tres`：浅金纸底、棕金边框、深棕字、菱形选中标记与金色滚动条。弹出窗口显式绑定主题并关闭系统原生菜单，列表宽度跟随分类栏、逻辑高度230像素，长分类通过滚动显示；脚本只负责商品数据、选择逻辑及弹窗尺寸同步。

## 玩法与服务端

- 本地购买、装备、使用、丢弃按存档持久化结果确认，失败回滚；不上报联机。
- 联机固定目录由服务端加载；客户端只提交操作、物品 ID、数量及角色版本，不接受客户端价格、数值或外观字段。
- 一次事务更新余额、所有权、数量、槽位、操作回执及审计。回执可重放，过期角色版本拒绝执行。
- 装备每件一个、物品每组最多 99、背包 60 格；数据库约束固定 ID、装备数量与每个槽只能装备一件。
- `shop-v2` 快照携带目录摘要，避免反复传输整个物品表；三段外观表示兵器、衣服、头饰。旧协议保留六物品快照与两段外观兼容显示，仅转换网络响应，不改写完整回执或真实物品。
- 药品可从地图背包使用；战斗原有补血指令保持现有逻辑，尚未扩展为战斗中任选全部药品。

## 重建与验证

```sh
python tools/build_full_shop_catalog.py
python tools/import_hero_parts.py
python tests/test_full_shop_catalog.py
godot --headless --path client res://tests/hero_appearance_test.tscn
godot --headless --path client res://tests/full_shop_test.tscn
```

联机验证设置 `SSJX_TEST_SERVER_BIN` 指向隔离构建的服务端，运行 `tests/run_full_shop.py` 与 `tests/run_online_shop.py`；使用自行创建并销毁的 PostgreSQL，不读取正式数据库。设置 `GODOT_BIN` 后同时测试真实 Godot 购买、装备、头饰同步及背包。设置 `SSJX_SHOP_CAPTURE` 可保存商店与背包装备栏截图。

验证包含：208 个物品逐项购买、装备或使用、移除；全部图标加载；六个原始角色每一 ANI 帧像素一致；男女职业换装；十个槽位同时装备；数量/背包限制、职业限制、余额与属性、持久化、回执重放、事务失败回滚，以及同图外观广播。导出探针也验证全部物品图标与部件在实际包内，并创建完整换装角色。
