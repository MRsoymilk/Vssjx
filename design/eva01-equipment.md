性质：**已生成并接入源码的同人参考装备**。2026-10-20 按用户指定的 EVA 初号机主题制作，尚未打包、推送或部署；当前公网游戏和 APK 不会自动获得这些资源。

## 设计与范围

提取初号机的紫黑拘束装甲、荧绿条带、独角、白眼与金属下颌，加少量橙色核心点缀。保留原游戏六种人物的像素密度、头身比例、动作和握持结构，制作全覆面机械头盔及职业武器，不变成另一个高大机体。

这是 **AI 编写的 Pillow 确定性像素绘制脚本**：基于原生帧的透明轮廓重配色、补绘装甲纹理、独角盔和图标；未调用外部图片生成服务，没有复制官方插画、NERV 标志或文字。作品参考与原包底层素材的权利分别核验，不代表官方授权或原版恢复资源。

## 游戏入口与规则

本地启动新源码：菜单 → 商城 → 热卖／奇珍 → **初号机 · 本角色**，每个人物可购买并穿戴十件配套装备。项目数据管理“装备外观”中搜索 `ai/eva01/`，可按单件或整套对照。

物品 ID 为 `ai/eva01/<mzs,wzs,mck,wck,mfs,wfs>/<slot>`；完整外观如 `hero/mzs_w40_c24_h22`。武器 140 铜钱、攻击 +14，其余九件各 70 铜钱、防御 +3，全套 770 铜钱。一级可用，严格限制职业和性别，没有额外套装属性。

仅武器、衣服、头部三项有独立外观层，其余七槽只有独立图标及属性。衣服视觉包含整套护甲／裤靴，不把单独装备鞋子描述为改变人物外观。

## 资源与复现

- `tools/build_eva01_equipment.py`：绘制和发布 30 张原生部件图集、60 张 32×32 透明图标。
- `client/assets/data/eva01-equipment.json`：六套外观、职业、性别和原生帧区域。
- `client/assets/generated/equipment/eva01/`：正式运行时纹理。
- `analysis/ai-generated/equipment/eva01/`：配色、参考说明、模板／生成器哈希与全部产物 SHA256。

身体／武器逐帧保持原始 alpha 轮廓与握持点；空帧不补画。头部主帧重绘为独角盔，底部接缝和第二段下发／护颈保持原始 alpha，避免把下发段误当成另一个朝向。没有改写原生 ANI、原包图集或之前两系列的图片。

```sh
python tools/build_eva01_equipment.py
python tools/build_full_shop_catalog.py
python tools/build_eva01_equipment.py --migration
```

93 个资源／清单／记录重跑后逐字节一致。完整目录现在为 394 项：208 个原包重建物品、6 个兼容物品、三系列各 60 件装备。新增 `0023_eva01_equipment.sql` 配套扩展允许 ID 与十槽约束，保留旧库存；未向正式数据库应用迁移。

联网仍由服务端确认价格、属性和穿戴，客户端与服务端的目录摘要须配套更新。仅更新本地图片不等于已在旧线上服务或既有安装包接入。

## 验证边界

实际 Godot 4.7.2、独立 Xvfb、Mesa llvmpipe OpenGL ES 离屏渲染通过，含五类动作、商城、地图、背包及管理面板。临时 PostgreSQL／Rust 服务检查购买、十槽、非法穿戴、同步和重连；不读取真实玩家数据。计数、命令与截图位置见 [验证记录](../tests/eva01_equipment.md)。
