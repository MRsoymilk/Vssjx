# 五角色创建与选择（2026-10-17）

沿用原选角页面的五个指示位置，本地和联机最多各五个角色。已有角色时仍可从“菜单 → 创建角色”新增；满额后禁用创建，创建完成返回选择页并选中新角色，左右箭头切换后点击“进入”。不改页面配色和布局。

## 联机

`0008_multiple_characters.sql` 保留已有角色、物品和回执，将旧角色放在零号槽位。账号角色使用 `slot=0..4` 和 `(account_id,slot)` 唯一索引，创建事务持有原来的账号行锁，选择最小空槽，因此并发创建最多五个。原创建回执先于容量检查，未知结果重试仍返回原角色，不重复发放物品。

列表按槽位和 ID 排序，返回最多五个角色；昵称仍全服唯一。客户端校验列表容量与重复 ID；创建回执合并新角色，保留原列表和已有角色的新修订，再从服务端刷新完整列表。创建页面不会因为账号已有角色就自动退出。角色进入、库存、任务、战斗与属性仍按各自 UUID 归属，不改服务器玩法规则。

## 本地

旧版单角色 v1 文件仍可读取，进入同一角色不会主动改写。新增角色后，在原存档中增加 `local_characters` 元数据（版本、当前 ID、最多五个角色快照）；当前角色的 v1 字段仍保留在顶层。单次原子写入同时保存当前角色与全部槽位，切换与新增不会覆盖其他角色。无需新增文件目录或从角色昵称生成路径，浏览器异步持久化继续沿用原有 storage 接口。

读取时检查槽位 ID、容量、每份角色数据、当前角色一致性，拒绝重复 ID、递归快照和缺失当前角色。创建前读取磁盘当前列表，保留旧角色的装备、背包、任务、金币、签名和刷新时间。保存失败会保留原文件并恢复原角色；同名本地角色会明确拒绝，避免未知写入结果重试造成重复。离线角色不上传，也不与账号角色混合。
