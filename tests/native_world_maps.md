# 全地图原生重建

范围为214张扩展地图及青云山道、古剑遗迹，共216张。仅使用现有Online原包素材；原始完整布局没有恢复，截图只证明局部结构，不能将重建设计称为原版还原。血魔祭坛、天丢谷仍是离线方案，不进入运行目录。

## 原生场景基础（阶段一）

- `client/scenes/maps/<map_id>.tscn`：一图一场景，可在Godot中独立打开；地表为真实`TileMapLayer`，树木为原生人物场景实例。
- `client/assets/map_resources/original_tiles.tres`：756张原包图块共用一份`TileSet`。目录仅保存路径，不预载整个世界。
- 本地及联机共用`NativeWorldMaps`，不再每次入图新建图块库或逐格解析JSON绘制地表。
- 任务、居民、出口、存档位置及协议哈希仍以共享数据为准；原生场景包含通行几何指纹供核验，不新增物理碰撞与服务端寻路竞争。
- `python tools/build_godot_maps.py --check`核查所有资源；首次生成不覆盖现有编辑，重新生成须先检查差异再显式`--force`。该命令只是源资源生成，不执行游戏打包。

阶段一验证：Python4项、Godot全图446,518项通过，覆盖全部格子的地表、服务端通行边界及全部树木锚点；AI世界与恢复NPC回归通过。原始共享JSON完全未改动。

## 全图美术重建（阶段二）

重建的是全部216张运行地图的**视觉场景和层次**，保留已验证的地理骨架、通行区和交互坐标，不为改布局而破坏存档。原版214张逐格布局仍没有恢复，不将这批场景当作反编译证据。

- 地表从语义地形重新配色铺贴：草地使用原包88号空白草皮，13/14号草簇降为成片稀疏点缀，避免每格一簇的网格感；道路用原包边角过渡，花木按局部区域分布。
- 雪岭使用原生雪面、冰岸及两级雪崖，而不再把普通蓝石地板当作整片雪地；熔岩深处使用原包熔流纹理。洞室只在平地使用裂纹细节，崖角不混作地板。
- 301处已知建筑从地表拆出为独立`TileMapLayer`，以地基底边参与Y排序。人物在建筑北侧被遮挡、走到南侧覆盖建筑；不是简单提高整层Z值。建筑本身的原包拼块保留。
- 补充地形外缘植被，所有新增树干只能落在原来已阻挡的边界格。出生点、居民、巡游点、完整出口条带及守境人周围保留树冠缓冲。竹林区继续使用竹子，黄土门院沿用秋树，昆仑截图庭院不会误加雪松。
- 花涧派北院、红顶殿、中央草阶及两侧三格出口保留；秋兰竹亭／幻波池保持竹林水岸语汇；已有11组截图适配继续有效。没有把未确认的截图地名或离线副本方案塞入运行世界。
- 驿路目录、管理页地形预览及小地图改读同一份原生视觉，不再显示旧JSON地表。预览只缓存最近6图；碰撞仍来自服务端共享数据，原生场景的几何指纹在加载时核验。

### 编辑与重建

在Godot打开`client/scenes/maps/ai_021.tscn`等场景即可直接编辑Ground、Scenery、建筑和原包TileSet。只调整图块／视觉分层不会改变游戏规则；**移动阻挡物、扩大场景或修改出口必须同时更新共享几何、验证客户端与服务器，不能只移动美术节点。**

`tools/original_map_art.py`是离线美术规则，不是运行时地图生成器。原生资源已有编辑时，普通生成命令会拒绝覆盖；`--force`只用于明确重新生成本批资源。新增原生改动应纳入相应生成规则或保留手工场景，不能盲目强制重建。

```sh
python tools/build_godot_maps.py --check
python -m unittest discover -s tests -p test_native_world_maps.py
SSJX_MAP_CAPTURE="$PWD/work/map-rebuild/native" \
XVFB_BIN=/tmp/opencode/vssjx-eva01-xvfb/run-xvfb LIBGL_ALWAYS_SOFTWARE=1 \
python tests/run_offscreen.py --path client --rendering-method gl_compatibility \
  --rendering-driver opengl3_es res://tests/native_world_maps_test.tscn
python tools/review_native_maps.py
```
