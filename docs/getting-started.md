## 本地与联机

- **本地模式**：无需游戏服务，角色、物品和任务保存在本机；不参与线上占名或社交关系。
- **联机模式**：先注册／登录，再创建或选择服务器角色。每账号最多五个线上角色，昵称全服唯一；客户端不能上传离线资产覆盖线上数据。
- **原生客户端地址**：支持 `127.0.0.1:8080`、`game.example.com` 或完整 HTTPS 地址，支持代理路径前缀。IP／localhost 省略协议时使用 HTTP，域名默认 HTTPS；非回环账号登录仍要求 HTTPS。
- **网页地址**：使用导出时确定的同源配置，不能将网页导出等同于任意跨站连接客户端；部署见 [网页入口](../deploy/WEB.md)。

账号名与角色昵称是不同字段。新角色选择职业、性别与昵称，以“闲云野鹤”身份出生；可找清微道人正式入派。当前技能按职业和等级开放，不受门派限制，详见 [入派流程](../design/school-membership.md) 和 [技能规则](../design/skills.md)。

## 基础操作

| 操作 | 方式 |
|---|---|
| 移动 | 点击地图自动寻路，或 WASD／方向键 |
| 交互 | 点击 NPC／怪物靠近，或 E／Enter 与附近目标交互 |
| 人物属性 | 菜单“人物属性”或 C |
| 地图与任务 | 底部工具栏；点击左上小地图可收起／展开 |
| 背包与商城 | 菜单或底部入口，选择物品查看可执行操作 |
| 公共聊天 | 联机地图底部“聊天”入口 |
| 返回 | 界面返回按钮或 Esc |

推荐初次流程：**创建角色 → 找清微道人领任务 → 装备青锋剑 → 击败三只山狼 → 领取奖励 → 东侧灵门 → 古剑遗迹妖王**。道人可恢复生命和灵力。

地图界面的“AI生成·驿路目录”提供扩展地点入口。生成地图、人物与任务有来源标识，不代表原版布局或完整原版活动；详见 [世界扩展](../design/ai-world.md)。

## 战斗

基础快捷键：**1** 攻击、**2** 技能、**3** 待机／防御、**4** 道具、**5** 查看、**6** 逃跑、**0** 自动／手动。点击人物或按 Enter 展开／收起指令，查看卡片可点击或 Esc 关闭。

有效行动才推进回合；播放期间锁定新指令。普通单人战斗、组队战场和玩家切磋的回合、奖励与断线规则不同，不能混用：

- [技能与状态效果](../design/skills.md)：消耗、解锁、重建公式与未知字段。
- [组队与多怪战斗](../design/teams.md)：2–5 人集合、准备、队长发起与统一结算。
- [玩家决斗](../design/player-duels.md)：双方同意、独立切磋资源，无常规资产奖励。

联机点击其他玩家可查看资料或发出邀请；好友与帮派通过菜单管理，具体边界见 [社交设计](../design/social.md)。这些功能需要客户端、服务端及数据库迁移相互匹配。

## 存档与凭据

原生本地存档默认位于 Godot 的 `user://shushan_save.json`；Windows 通常为 `%APPDATA%/Godot/app_userdata/蜀山剑侠 · 归来/`。自动保存、任务及战斗结算、正常退出会触发保存；出现失败提示时不要当作已成功落盘。

网页本地存档使用浏览器 IndexedDB，与网站来源和浏览器配置隔离。清理网站数据、隐私模式或更换来源可能影响存档，不应将浏览器存储当作备份服务。线上进度以服务端数据库为准。

原生服务器地址独立保存到 `user://connection.cfg`。默认不记住密码；可选“记住我”的保护范围与网页凭据隔离见 [账号与会话](../design/auth.md)。不要分享用户目录、存档或配置截图中的私人信息。

本地调试可使用 [本地控制指令](../design/local-controls.md)；该入口不能修改线上等级或资产。
