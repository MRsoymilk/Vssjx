## 再分发与运营前

1. 核验计划使用的原包、图片、参考资料、名称及其他第三方内容的权利来源，保留授权与署名要求。
2. 对无法确认授权范围的内容，先取得相应许可或替换为权利清晰的资源；不要以“已解码”“AI 生成”或“非商业”代替授权依据。
3. 保留可追溯的资源路径、来源成员、校验值及生成记录，不将推定映射或重建数值写成原版事实。
4. 分发程序或提供修改版网络服务时，同时履行适用的代码许可及第三方依赖义务。

如需反馈来源、署名或权利问题，请通过仓库 Issue 联系维护者，提供相关路径和可核验依据；涉及私人信息时不要将其公开附在 Issue 中。
