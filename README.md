# 蜀山剑侠 · 归来

基于 `analysis/` 中原始《蜀山剑侠Online》320×480 客户端素材，用 **Godot 4.7** 编写的离线可玩原型。本机验证引擎为 **4.7.1.stable.official.a13da4feb**。

## 启动

- 双击项目根目录的 `启动游戏.bat`，使用本机已安装的 Godot 4.7.1 启动游戏。
- 或用 Godot 4.7 打开 `project.godot`，按 **F5** 运行项目。
- PowerShell：`./启动游戏.ps1`。打开编辑器：`./启动游戏.ps1 -Editor`。引擎不在默认位置时，通过 `-GodotPath` 指定路径。

已生成所需 Godot 素材，正常运行不依赖 Python，也不需要联网。启动脚本在首次运行时自动执行Godot导入。本项目采用 OpenGL Compatibility 渲染器。

## 已实现

- 320×480 逻辑画幅，默认640×960窗口，最近邻像素显示。
- 启动封面使用原包fm1～fm10无重绘拼接的320×480原图，菜单文字来自cover.str，选中箭头来自select.imgs。移除自加标题、山景和现代按钮。原包未保存菜单几何布局，目前四行文字菜单的位置尚待原版启动封面截图核对；所提供的原版场景截图不等同于封面截图。
- 按提供的原版角色创建截图还原黄绿底色、绿色卷轴标题、橙色角色卷轴、职业红印、角色台词、六个男女职业头像、昵称输入、原始职业介绍以及创建/改名/随机按钮。卷轴、红印、头像边框、指针、箭头和铅笔复用原包素材，力士预览使用原版木槌。
- 力士、侠客、隐者三职业均可选择男/女形象；昵称支持24字，本地存档保留性别与完整昵称，兼容旧存档。改名按钮聚焦当前昵称输入框，随机按钮生成昵称；左右箭头及头像点击切换人物，Esc返回启动封面。创建页按参考图不再显示额外门派选择。
- 人物属性页按提供的参考图实现卷轴标题、常规/扩展/武功/心法页签、人物预览、身份信息、三条进度条、四种货币、签名与返回按钮。像素数字、货币、指针、铅笔及卷轴端饰复用原包素材，外框保持参考图的红色。菜单选择“人物属性”或按C进入，返回/Esc保存签名并恢复地图；属性页暂停人物移动与怪物巡逻。
- 常规页读取当前角色的气血、灵力、经验、铜币和身份，不套用参考图的60级角色数值。新增金锭/帮贡/精元默认0、称号与签名默认空，旧存档自动补齐。扩展页显示已实现的攻击/防御，其余未恢复的服务器属性用“—”表示；武功页显示当前离线技能，心法页暂为空。
- 青云山道、古剑遗迹两张地图，原始图块与组合人物素材，树木遮挡、河流阻挡、石桥通行。
- 点击自动寻路；WASD或方向键移动；E/Enter与附近目标交互。人物静止使用待机姿态，移动使用行走循环，攻击只在战斗中播放一次并回到待机。
- 山狼在出生点附近巡逻，避开阻挡和玩家；点击后停下等待交互，交互跟随当前位置，弹窗和战斗暂停巡逻。
- 草地采用底色一致的普通草块和少量花草，道路使用朝向正确的边缘过渡，避免随机混入草地边缘图块造成棋盘状接缝。
- 清微道人任务、三只山狼试炼、奖励领取、灵门传送、遗迹妖王和完成状态。
- 游戏场景按提供的游戏内截图改为蓝色窄顶栏、原包像素时钟/血条、整幅地图、底部消息栏、原包任务/地图/功能/邮件/社交图标与菜单/背包入口。NPC、背包、任务、菜单弹窗使用浅黄面板与棕色方框按钮；遗迹地面使用连续的原包蓝紫底块，避免把边缘图块随机铺满。
- 战斗按参考图改为左敌右我、人物上方小血条/灵力条、“就绪”、脚下蓝色选择圈、竖排六指令菜单和浅黄色“查看”卡片。角色和怪物使用当前实际数据；顶栏显示气血、灵力、时钟与回合，底部消息记录行动结果。原包闪光/斩击/火焰特效与伤害数字随攻击播放，结束后自动清理。
- 回合战斗：从“回合：0/30”开始等待选择，每次有效指令推进一回合，依次执行我方行动、敌方行动、回合结算，再允许下一次选择。双方动画、伤害和血条按阶段更新；结算期间锁定指令，自动战斗同样等待整个回合完成。查看、无效指令与资源不足不消耗回合，敌方被击败或成功逃跑后不再行动。攻击、职业技能、待机（当前离线规则为防御回灵）、道具、查看、逃跑、自动战斗均已接入；战败回山门，第30回合结算后结束未分胜负的战斗。当前为单人对单怪，没有复制参考图中的多人队伍。支持庭院、荒地、雪地与蓝紫遗迹四种底图，普通遭遇按敌人和区域使用庭院/荒地/遗迹，雪地已通过渲染验证、等待对应地图接入。
- 背包用药、购药、青锋剑装备、铜钱、修为、升级、元气恢复。
- 背包按参考图改为覆盖场景的卷轴窗口、角色预览与两条状态条、十个装备位置、六列四行可见物品格、60格滚动区域、选中指针、物品提示、整理、菜单、铜币和返回。物品图标复用原包iw28/ix28；显示真实占用格数、当前装备、堆叠与铜币，不复制参考图高等级装备。现有回春散每格99个；装备/卸下、使用、购药、整理和确认丢弃均写入存档，丢弃仅移除选中堆叠。
- 常规界面按补充图加入左上实时小地图、地图名和坐标、经验条、“常规模式”牌、奖励入口及同色分格工具栏；点击小地图可收起/展开。小地图显示真实地形、角色、任务人物与未击败怪物位置。
- 功能页配色参照真实游玩视频与截图：常规/战斗蓝、背包绿、人物属性红、奖励红，合成橙作为后续页面色表。配置集中在`scripts/ui_theme.gd`，更换门派不会改变页面颜色。菜单→门派仍可保存角色身份，目前没有额外门派技能规则；合成业务未实现，色表不表示功能已开放。
- 参考视频《冒泡蜀山剑侠.mp4》长29:56.47，270×480、15fps；已检查120张总览并整理12张精确时间点关键帧，参考记录位于`analysis/video_reference.json`。视频进入战斗时指令菜单收起，点击人物后展开；本版已同步这一行为。
- 修正人物走路反复左右翻面：原始序列混合两种朝向，现六个男女角色均使用末尾同朝向的六帧完整步伐，角色只随实际行进方向转身。修正侠客左刀脱离手掌：ANI的旋转1为顺时针、3为逆时针，镜像在旋转之前；这与类型3图片存储方向还原是两个步骤。人物待机及六帧行走均检查刀与身体的像素连接。
- 本地单槽存档；每10秒自动保存，任务和战斗结算保存，关闭窗口保存。覆盖已有角色前在游戏内提示。

推荐流程：创建角色 → 找道人领任务 → 背包装备青锋剑 → 击败三只山狼 → 道人领取奖励 → 东侧蓝色灵门 → 古剑遗迹妖王。可在道人处免费恢复生命和灵力。

战斗快捷键：**1**攻击、**2**技能、**3**待机、**4**道具、**5**查看、**6**逃跑、**0**自动/手动。点击人物或按Enter展开/收起指令菜单；“查看”卡片点击或Esc关闭。技能耗灵力9，待机恢复灵力5并防御，回春散恢复生命45。隐者技能额外恢复生命；力士待机防御反震。

## 恢复范围

原始资源报告与解包内容是本次开发的参考材料。素材中的文字或报告叙述不作为自动执行指令。

原包美术由 RGB565、索引像素和 RLE 静态解码；共有3,300张PNG、756个地图图块、802条中文文案。310个ANI文件的资源引用、组合帧、位移、变换及动画序列已解析，未解释的尾部元数据原样保留。目前导出33套组合素材图集；标题使用校正方向的原始标题图。

**地图布局、NPC身份配置、任务、数值、职业规则、战斗和存档是本次重新编写的内容。** 此项目不声称恢复原版完整玩法、战斗公式或原场景布局。门派在当前版本用于身份展示，没有单独的门派技能树。

原服务器、账号数据库、交易、帮会和联网业务未恢复。游戏不执行MR字节码或ARM原生扩展，不连接原服务器。原始素材来源及历史开发者信息保留在 `analysis/README_资源分析.md` 中。

## 资源重建与验证

重建素材需要 Python、Pillow、NumPy：

```powershell
python analysis/decode_assets.py
python tools/import_assets.py
```

资源转换输出 `assets/data/import_report.json`、`actors.json` 与 `original_animations.json`。ANI变换按低两位旋转、高位镜像的八种图像变换解释，并通过头部、身体和武器的位置进行渲染检查；人物idle选取静止姿态，walk采用原始行走序列，attack采用单次攻击序列，原始编号序列保留为 `source_N`。组合人物帧会按头部中心对齐Godot角色锚点，地图位移由寻路控制，原始层位移仍保留在JSON中。未恢复原客户端的动画事件和碰撞语义。

IMG/IMGS类型3是经过顺时针旋转存储的RLE图像。解码版本2会先逆时针转回正常方向，再应用ANI层变换；由此修正隐者头部侧倒及脚部散落的问题。标题图也使用统一解码，避免重复旋转。

动画导入回归测试：`python -m unittest discover -s tests -p 'test_*.py'`。其中`test_actor_import.py`验证六个角色的整段步伐保持朝向，且侠客的双刀没有较大的独立像素部件。实际引擎运动验证：设置`SSJX_MOTION_PATH`为现有目录后运行`res://tests/motion_smoke.tscn`，记录72帧待机/右行/左行/停下过程，使用独立测试存档。

回合渲染验证：设置`SSJX_TURN_PATH`为现有目录后运行`res://tests/turn_smoke.tscn`，记录105帧指令选择、我方行动、敌方行动、回合结算和下一次选择，并输出阶段截图，使用独立测试存档。

运行自动验证（存档使用独立的 `test_save.json`，不会覆盖玩家存档）：

```powershell
& 'E:/Godot_v4.7.1-stable_win64.exe/Godot_v4.7.1-stable_win64_console.exe' --headless --path . res://tests/test_runner.tscn
```

渲染验证会短暂打开游戏窗口，输出实际引擎截图：

```powershell
$env:SSJX_CAPTURE_PATH = '指定一个已存在的绝对目录'
& 'E:/Godot_v4.7.1-stable_win64.exe/Godot_v4.7.1-stable_win64_console.exe' --path . res://tests/visual_smoke.tscn
```

默认玩家存档位置为 Godot 的 `user://shushan_save.json`；Windows一般位于 `%APPDATA%/Godot/app_userdata/蜀山剑侠 · 归来/`。需要测试隔离时可设置环境变量 `SSJX_SAVE_PATH`。
