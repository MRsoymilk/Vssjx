# .env配置与Git排除验证

命令从仓库根目录执行：

```sh
cargo test --locked --manifest-path server/Cargo.toml
python tests/run_env_config.py
```

Rust用例位于`server/tests/config.rs`，检查样例默认值、变量引用、只读解析、参数边界、空数据库URL及错误脱敏。不会修改全局进程环境或读取真实私有密码做断言。

实际进程脚本创建专属临时`.env`并启动Rust，覆盖：

- 指定文件、当前目录自动发现，以及环境变量覆盖文件。
- 空的环境数据库URL可以覆盖文件URL，避免连接私有数据库。
- `SSJX_ENV_FILE=''`完全禁用读取，即使当前目录含损坏配置也不读取。
- 指定文件不存在或解析失败时退出，错误不包含敏感配置行。
- `.env`被Git忽略且未跟踪，`.env.sample.txt`不被忽略。
- 使用样例及临时密码执行Compose静态校验，不启动持久化开发数据库。

脚本不打开数据库；真实数据库联调仍运行`tests/run_account_auth.py`。账号联调现在显式禁用私有`.env`读取，并通过专属进程环境配置访问120秒/刷新600秒，以验证期限确实来自配置而非硬编码。数据库实例仍由隔离容器提供。

原地址联调`tests/run_server_connection.py`同样禁用私有配置；不能因为本机`.env`启用了账号而误连个人数据库。

Git历史消息修正仅改变提交消息及后续提交的父引用；修正前后HEAD树、工作区和暂存区一致，保留原历史备份引用，未推送或强推远端。此项不是游戏逻辑或容量验收。

本轮结果：Rust共11项案例通过，实际`.env`进程读取/覆盖/脱敏与Git排除检查通过；真实PostgreSQL账号流程、21项离屏账号界面检查、56项连接检查及跨进程地址恢复、379项现有玩法回归和12项Python回归均通过。真实数据库验证使用隔离容器，未读取私有`.env`中的数据库地址。
