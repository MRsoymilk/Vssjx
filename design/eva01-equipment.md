性质：**已生成并接入源码的同人参考装备**。2026-10-21 按“参考原版装备美化，贴合人物身体”的要求更新六套外观。当前改动未打包、推送或部署；公网和已安装 APK 需后续更新才会获得新版资源。

## 设计与范围

采用紫黑甲衣、柔和玉绿镶边、浅紫高光和少量金色扣饰。衣装改用六种人物各自的原版七阶部件 `*7 / *7q / *7x`，保留褶皱、袖口、手部肤色及原始身形。头部保留原生 `*t2` 的脸型、眼睛、发型和完整下发段，只在发丝内增加小型碧玉冠饰；原先统一的封闭机械头盔已替换。

使用内置 **image_gen**、原版六角色衣装截图生成设计参考，随后按原生图集进行确定性的材质适配，避免缩放整张AI立绘导致脸型、身体和连接点变形。生成参考、完整提示词和原版参考保存在 `analysis/ai-generated/equipment/eva01/refinement-v2/`；参考图不是动画图集。九个非武器图标沿用原包紫霄系列的轮廓和阴影，再适配当前配色。新设计属于同人参考，不是原版恢复结论。

## 游戏入口与规则

本地启动新源码：菜单 → 商城 → 热卖／奇珍 → **初号机 · 本角色**，每个人物可购买并穿戴十件配套装备。项目数据管理“装备外观”中搜索 `ai/eva01/`，可按单件或整套对照。

物品 ID 为 `ai/eva01/<mzs,wzs,mck,wck,mfs,wfs>/<slot>`；完整外观如 `hero/mzs_w40_c24_h22`。武器 140 铜钱、攻击 +14，其余九件各 70 铜钱、防御 +3，全套 770 铜钱。一级可用，严格限制职业和性别，没有额外套装属性。

仅武器、衣服、头部三项有独立外观层，其余七槽只有独立图标及属性。衣服视觉包含整套护甲／裤靴，不把单独装备鞋子描述为改变人物外观。

## 资源与复现

- `tools/build_eva01_equipment.py`：绘制和发布 30 张原生部件图集、60 张 32×32 透明图标。
- `tools/eva01_native_style.py`：原生材质分区、肤色保护、冠饰与原版图标适配。
- `client/assets/data/eva01-equipment.json`：六套外观、职业、性别和原生帧区域。
- `client/assets/generated/equipment/eva01/`：正式运行时纹理。
- `analysis/ai-generated/equipment/eva01/`：配色、参考说明、模板／生成器哈希与全部产物 SHA256。

所有部件逐帧保持原始 alpha 轮廓与握持点，空帧不补画。脸部肤色、五官和第二段下发保持原图；冠饰限制在原有发丝内，不增加游离像素。实际 Godot 合成图集与“原版七阶衣装＋同发型＋同武器”逐 alpha 字节比较，全部姿势一致。发布清单使用平台无关的正斜杠资源路径，只清理该系列旧清单中已无引用的图集。

```sh
python tools/build_eva01_equipment.py
python tools/build_full_shop_catalog.py
python tests/test_eva01_assets.py
```

运行时资源与清单可确定性重建；图像生成参考单独持久化。完整目录为396项。`0023_eva01_equipment.sql` 是历史新增物品迁移，本次美化不重写该迁移，也不新增数据库变更。

联网仍由服务端确认价格、属性和穿戴，客户端与服务端的目录摘要须配套更新。仅更新本地图片不等于已在旧线上服务或既有安装包接入。
