# 游戏内世界地图

## 本地地图界面

- 地图入口与3键打开`world_map.tscn`，采用参考图的橙金上下栏、野外/城市/门派图例、半透明场景底图、白色连线、地点名称和等级提示。
- `world_map_graph.tscn`预置79个原版图标和78条原始线段。位置、类型、等级读取已核验的Online v48总图；保留原始异常端点，不生成额外地点或场景布局。
- 初次选择参考图中的“卧云镇北”（20～25级），这是浏览选择，不冒充当前游戏场景的原版地图编号。支持点击选择、鼠标/触屏拖动、滚轮及方向键浏览，图例定位对应类型，0键循环定位四个城市。
- 本地打开时暂停行走，返回及Esc恢复同一场景。神行符数量未接入，显示“—”且禁止传送，不使用参考图中的99伪造库存。
- 本地地图21项检查通过，包含所有图标位置与原始线段逐项对比；真实渲染已检查，菜单57项回归通过。设置`SSJX_WORLD_MAP_CAPTURE_PATH`可生成截图（真实图形模式）。
