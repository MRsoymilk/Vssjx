# 游戏弹出菜单

本地和多人界面均引用 `client/scenes/ui/game_menu.tscn`，点击底部“菜单”或动作图标时，在左下方工具栏上方展开窄幅竖排面板。按用户确认使用“人物”，移除充值及所有数字编号，顺序固定为：商城、人物、炼制、社交、任务、队伍、帮会、交易、系统、帮助。

十个按钮、浅色面板、棕色字体、金色选中条均在tscn定义。鼠标悬停或上下键可移动选中条，点击或Enter/空格直接进入对应功能；Escape或点击菜单外收起。没有数字快捷键或额外确认栏。打开菜单会阻止键盘移动输入，联机角色与消息仍继续更新。

本地人物进入原属性页，任务显示真实任务进度，社交使用现有本地状态提示。多人社交打开好友面板，队伍和帮会进入各自已实现的面板；人物只读取该账号的线上快照。没有可用状态的入口仍显示相应提示，不扣费或模拟交易。菜单末尾的帮助共用控制指令说明页，详情见 [默认本地入口与帮助回归](local_help.md)。

本地“系统”使用 `system_menu.tscn`，保留返回游戏、保存进度、门派、调息和保存后返回登陆。多人“系统”保留线上状态、返回游戏/登陆及公共聊天入口，不调用本地存档。

## 验证

```sh
godot --headless --path client res://tests/game_menu_test.tscn
godot --headless --path client res://tests/test_runner.tscn
godot --headless --path client res://tests/shared_interface_test.tscn
godot --headless --path client res://tests/chat_emotes_test.tscn
godot --headless --path client res://tests/ui_scenes_test.tscn
```

`game_menu_test` 使用隔离本地存档与连接配置，覆盖双方使用同一场景、十项顺序且无充值/编号、布局、悬停/键盘选中、直接进入人物和任务、未开放入口无资产变更、关闭/移动焦点、系统手动保存和返回登陆，以及线上菜单不修改本地角色或存档。线上部分使用实际界面及协议状态夹具，不连接生产服务器或数据库。

设置 `SSJX_MENU_CAPTURE_PATH` 为已存在目录后，以真实渲染运行该场景，会保存本地菜单、多人菜单及系统页及本地／联机帮助页五张截图。
