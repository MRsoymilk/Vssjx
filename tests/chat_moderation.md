# 聊天管理与公网发布验收（2026-10-18）

管理员通过原 SSH 隧道访问 `http://127.0.0.1:9091/chat`。支持按角色名、账号、正文筛选最近发言，按账号筛选，删除指定消息，账号禁言10分钟／30分钟／1小时／24小时，以及解除禁言。处理需填写公开原因，结果作为系统消息进入游戏聊天框。禁言覆盖账号全部角色，保存至现有 `accounts.chat_muted_until`，重启后继续生效。

聊天正文继续只保留于当前服务的有界内存缓存，管理页每3秒刷新。删除会清理原文及发送回执原文，保留序号占位，并同步撤回已显示的原文；公开客户端不获得账号用户名或账号ID。审计只记录处理信息和原因，不记录被删除正文。幂等操作号、请求摘要、账号锁与审计写入同一事务，审计失败时操作回滚。
