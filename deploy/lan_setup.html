与服务器连接同一个局域网。首次访问先安装并信任本机生成的局域网证书，之后即可直接进入游戏，各自注册或登录账号。

首次安装证书

下载证书（Android / Windows） · 下载 iPhone / iPad 配置描述文件

Android：在系统设置中搜索“安装证书”，选择“CA 证书”，安装下载的证书。不同品牌的入口名称可能不同。完成后用 Chrome 等浏览器访问游戏。

iPhone / iPad：用 Safari 下载描述文件，在“设置 → 通用 → VPN 与设备管理”安装，然后到“通用 → 关于本机 → 证书信任设置”，开启这张根证书的完全信任。Apple 官方说明。

Windows：打开证书，选择“安装证书 → 当前用户 → 将所有证书放入下列存储 → 受信任的根证书颁发机构”。完成后重新打开浏览器。
