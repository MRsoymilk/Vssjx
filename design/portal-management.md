# 门户统计与 APK 文件管理

[返回设计索引](README.md) · [导航设计](portal-navigation.md) · [操作说明](../deploy/PORTAL_STATS.md) · [验证入口](../tests/portal_stats.md)

性质：**本地已实现的独立管理能力，未部署**。源码变化不代表 2026-10-19 的线上门户已开启统计或 APK 管理；不改历史发布事实。

## 分层与权限

```text
门户入口 → Nginx 固定跳转／静态请求 → 白名单 JSON 事件 → 容器 stdout
                                                    ↓ 宿主采集 CLI
                                                独立 SQLite
                                                    ↓ 只读汇总
                                          回环管理 UI / CSV
                                                    ↓ 显式写操作
                                       私有 APK 库 → 独立公开副本
```

采集与管理是不同命令。管理 HTTP 服务不访问 Docker、游戏账号或 PostgreSQL，不提供任意 SQL、文件路径、日志导入或命令执行接口。后台只绑定回环 IP，通过 SSH 隧道使用，不为公网增加统计查询入口。

写操作验证实际 TCP 对端、单一合法 Host、同源 Origin、浏览器来源及随机进程令牌；重启即更换令牌，不接受跨站写入。私有后台没有另一个密码系统，同机可信用户可以访问，不能充当多租户鉴权服务。

## 指标口径

| 指标 | 来源与限制 |
|---|---|
| 门户 PV | 门户 HTML 的 GET 200／304，含刷新与预览，不是独立人数 |
| 网页入口点击 | `/go/webgame` GET 302，只固定跳往 `/webgame/` |
| Android 入口点击 | `/go/android` GET 302，只固定跳往原 APK 路径 |
| 游戏页面访问 | 新旧游戏 HTML 的 GET 200／304，含直达和刷新 |
| APK 请求 | 文件 GET 200／206；完整响应请求与分段请求分别保留 |
| 缓存／异常 | 304 及 4xx／5xx 单列，不当作完成下载 |
| 发送流量 | 200／206 的响应正文发送字节，不含错误页、响应头或设备落盘证明 |

HEAD、API、WSS、CSS、图片、游戏引擎文件与后台请求不产生统计事件。页内锚点、鼠标操作不采集。脚本／机器人也能请求公开入口，因此这些指标不是防作弊的人级计数或付费结算依据。

事件仅包含随机请求 ID、时间、闭集路由 ID、状态与正文发送字节；没有 IP、原始 URL、查询参数、UA、Referer、账号或凭据。Nginx 既有错误日志不作为统计明细写入数据库。门户仍没有 JavaScript 统计代码或访客 Cookie。

## 一致性与留存

请求 ID 和事件摘要与日汇总在同一 SQLite 事务提交；重放同一事件不重复计数，同 ID 不同内容记录冲突。采集器断线重连后重读仍保留的 Docker 日志，不依赖容易丢失的内存游标。

去重 ID 保留 30 个自然日，日汇总不自动删除。清理去重记录时推进不可倒退的退休日期；早于该日期的日志不再导入，避免清理后重复计数。日志容器重建、轮转丢弃或采集中断超过日志保留窗口可能导致漏计，不能声称永久 exactly-once。历史关闭日志时的数据无法补回。

## APK 管理

- 私有包使用随机 ID 文件名、受限目录和独立登记库；原文件名仅用于安全显示，不进入存储路径。
- 默认单文件 256 MiB、私有上传总量 1 GiB。限制长度、时间和 ZIP 中央目录／成员／清单，拒绝路径穿越、重复成员、加密条目和不支持的 ZIP64；不解包、不执行、不做签名或安装安全认证。
- 同 SHA256 重复上传复用登记，不自动发布。当前包、未知发布目录及被修改的文件受保护。
- 发布先准备完整副本及校验文件，再原子切换相对 `current` 符号链接；后台发布不自动重载 Nginx。私有库和公开副本必须分开配置。
- 当前版本不能删除；旧版需二次确认，只删除后台登记且摘要匹配的文件。删除状态落库，已开始删除的旧版可按原 ID 安全重试，未知文件不清理。
- 新的可选只读 Nginx 挂载仅提供公开副本的当前 APK／校验文件。未挂载或未发布时沿用原下载，原网页导出目录的 APK 不会被接管或删除。

文件数据和目录变更进行 fsync，文件登记与发布指针在故障后仍需按实际磁盘状态核对；系统／磁盘丢失仍依赖备份。私有上传与发布副本各占空间，应额外预留副本和临时文件容量。

## 发布边界

本轮不启动远程服务、不启用线上日志、不替换线上 APK，也不推送。未来启用需分别核验日志采集权限、管理端回环边界、独立目录权限及 Nginx 只读挂载；新增挂载可能需要单独重建代理容器，不能将其描述为纯 reload。游戏服务和数据库不因这套管理能力而需要重建或迁移。
