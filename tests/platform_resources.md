# P1b：原生资源准备接口与战斗接入

本单元承接[平台基础P1a](platform_interface.md)，实现[平台方案](../design/platform_interface.md)中的`ResourceLoaderInterface`原生路径。没有新增Web预设，也不把原生线程验证当作单线程Web、Safari或Android浏览器验收。

## 实现契约

- `Platform.context.resource_loader.prepare(paths, owner, generation, type_hint, timeout_msec)`返回可轮询的`PlatformResourceRequest`，包括唯一请求编号、调用方代次、单调进度和终态`PlatformResult`。没有保留场景闭包或直接调用场景的完成回调。
- 只准备现有`res://`包内资源；先验证完整清单，拒绝空清单、超出128项、远程/用户文件路径、不存在的资源、非Resource类型、负代次和无效超时。重复路径只计一项实际工作。
- 原生继续使用Godot线程资源加载和引擎缓存，不新增磁盘缓存、远程下载、分包或第二套永久强引用缓存。并发消费者共享同一路径的引擎任务，但每个请求有独立的进度、取消、超时和类型检查。
- 成功结果持有强资源引用，避免准备完就被弱缓存回收；只有全清单成功，进度才到1。失败不暴露部分结果，不把损坏、错类型、线程请求拒绝或超时当作成功。
- `cancel()`立即使该消费者进入取消终态；其他共享消费者不受影响。已完成的结果不能被晚到的取消、进度或底层完成覆盖。
- 所有者是弱引用；离树、排队删除或释放后，待处理请求取消。适配器退出时也解析为取消，不留下永远等待的句柄。取消不承诺物理中止底层引擎线程；平台继续收取已完成的孤立任务，不向旧场景派发结果。
- 进度按每个唯一资源的实际准备状态汇总，不表示下载百分比。平台只准备引擎资源；`OriginalArt`的元数据和SpriteFrames组装仍在游戏资源层，继续按原有四组角色/特效逐帧准备，不让平台认识角色、地图、奖励或战斗流程。
- 战斗页面不再直接调用`ResourceLoader.*`。它传入遇敌代次并保留原来的代次/世界实例屏障，离开或切换页面时取消并释放句柄；只有当前请求成功才继续动作准备与战斗创建。失败展示平台原因，可关闭提示后恢复移动，不扣资源、不发奖、不自动补发战斗指令。

## 可执行检查

```sh
python -m unittest discover -s tests -p 'test_*.py'
python tests/run_platform_interface.py --render --network --output /tmp/opencode/vssjx-platform-resource-validation
python tests/run_game_export.py --output /tmp/opencode/vssjx-platform-resource-export
```

平台执行器沿用独立源码副本、协议夹具、XDG目录和存档；真实渲染需要[testing.md](testing.md)中的Xvfb/Mesa配置。管理工具仅在PC原生桌面使用，不纳入Web/手机适配、浏览器测试或游戏导出；管理场景及玩家数据不在本单元改动范围。

`resource_loader_test.tscn`覆盖真实包内纹理的冷加载、并发取消和引擎缓存复用，并用`tests/fixtures/resource_loader_backend.gd`注入确定性的进度、时钟与IO状态，检查：

- 清单预校验、重复路径和独立请求身份。
- 部分进度、回退观测、NaN、完成条件和强引用身份。
- 共享任务只取一次结果，取消一个消费者不影响另一个。
- 所有者被释放/排队删除、新代次请求、取消后的孤立完成及适配器销毁。
- 线程启动失败、批次中途失败、错类型和不同消费者的超时。

原生错误注入不是对Web线程、底层磁盘故障或解码峰值的实测。`battle_transition_test.tscn`另行覆盖正常遇敌、加载中取消、较新战斗不被替换、缺资源恢复及角色资源不变；真实渲染产物在执行目录的`encounter-screenshots/`。

两个游戏预设的PCK审计新增包内资源接口检查：从实际导出的包中异步准备纹理并核对终态和代次；不从源码路径拿资源冒充打包成功。完整Windows可执行文件仍需对应模板和实际运行验收。

## 后续边界

本单元完成时尚待接入的输入和系统动作已在后续[P1c](platform_input_actions.md)建立原生基础实现。P2仍需单线程Web资源策略、异步存储、网页外壳、受控配置、凭据边界与精确Origin白名单。单个资源解码耗时、Web内存及手机前后台等仍须相应环境实测，不能因为逐帧轮询就宣称所有加载无卡顿。
