# P1c：文本输入与原生系统动作

承接[基础接口](platform_interface.md)和[资源准备](platform_resources.md)，建立其余两个计划中的接口类型并接入真实调用方。当前只实现Godot输入框协作和原生退出请求；不是音频、全屏、HTML输入桥接或手机中文输入验收完成声明。

## 实现范围

- `Platform.context.text_input`提供焦点请求、焦点释放和提交前检查。公共实现使用Godot `LineEdit`，不读取、保留或记录账号、密码、聊天、昵称或签名内容。
- 提交检查接受动态控件数组，逐项验证类型、在树内、可见和未排队释放；返回稳定的`INPUT_UNAVAILABLE`或`INPUT_COMPOSING`等结果，不通过脚本类型异常表达失败。只读输入框仍可参加重试/选角表单，业务锁定和字段规则不移到平台层。
- 原生组合状态查询使用锁定引擎实际提供的`LineEdit.has_ime_text()`；存在未确认候选时，登录、注册、角色创建和聊天入口不发起请求、不生成操作ID、不清空草稿。原有昵称、密码、消息规则和幂等回执不变。
- 登录、创建页、聊天及签名编辑的程序化焦点操作经接口进行；不强制`apply_ime()`，也不注入浏览器HTML输入层。表情插入不覆盖仍处于组合输入的草稿。
- `Platform.context.system_actions.request_exit()`在原生侧请求`SceneTree.quit()`。成功只表示退出请求已接受，不表示业务已保存或进程已经完成退出；保存、战斗关闭和结算仍由原来的页面逻辑执行。
- 封面退出和窗口关闭均经系统接口；窗口关闭保持原有先保存离线进度、再请求退出的顺序。基础契约和未就绪/不支持路径明确返回失败，页面保留可读提示，而非静默假成功。
- 原生与Web/手机不等同。没有把原生退出实现用于关闭浏览器标签页，没有增加未使用的音频/全屏空壳，也没有修改仅在PC使用的admin工具。

## 执行入口与隔离

```sh
python tests/run_platform_interface.py --render --network --output /tmp/opencode/vssjx-platform-input-acceptance
python tests/run_game_export.py --output /tmp/opencode/vssjx-platform-input-export-acceptance
python -m unittest discover -s tests -p 'test_*.py'
```

执行器使用独立源码副本、协议夹具、配置、用户数据与测试存档，不继承开发者的`SSJX_*`端点和秘密；真实渲染环境配置见[testing.md](testing.md)。当前工作树中已有的admin素材改动不属于本单元提交范围，导出仍排除管理场景、脚本、专用资源及测试。

新测试入口：

- `platform_input_actions_test.tscn`：在真实Godot控件上检查焦点/选择、隐藏与排队释放、动态错误参数、只读重试、草稿保留和提交防护，并覆盖登录、注册、在线/离线创建、聊天及窗口关闭保存顺序。
- `fixtures/text_input_backend.gd`：仅注入“当前有组合输入”的布尔结果；实际焦点和控件验证仍运行公共实现。它不模拟完整系统输入法，不可作为中文候选、粘贴或浏览器键盘真机验收。
- `fixtures/system_actions_backend.gd`：验证调用顺序及不支持时的提示，不在主测试进程中真正退出。
- `platform_exit_probe.tscn`：两个独立Godot无头进程实际结束，覆盖封面确认按钮与窗口关闭通知路径；窗口关闭进程的离线v1存档由执行器在进程结束后读取，核对昵称与铜钱73，防止只用伪后端计数冒充退出与保存通过。这不是点击真实操作系统窗口关闭按钮的验收。
- PCK审计从实际导出包打开登录页，验证文本接口焦点与提交检查、系统动作实例，不能回退到源码资源冒充打包成功。

## 尚未验收

P1的七类接口已具备原生基础接入，但不代表所有目标环境的P1退出条件已通过。Windows原生实际运行、系统中文IME的候选确认事件顺序、软键盘、触摸/模拟鼠标去重、失焦持续输入清理、页面回收与网络恢复仍须相应环境验证。

下一步进入P2所需的Web实现：受控同域配置、凭据边界、单线程资源策略、异步持久化、网页外壳、精确Origin白名单及真实浏览器闭环。`RememberedLogin`的已有原生行为本轮未改动，不能未经处理直接复用到浏览器。音频、全屏和可选HTML输入桥接随实际接入实现，不以空方法宣称支持。
