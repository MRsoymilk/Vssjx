# 展开聊天窗口

- 底部聊天框右侧增加向上箭头，使用用户提供的 `up-2-svgrepo-com.svg` 路径并调整为主题金色；滚动条箭头复用该路径。
- `client/scenes/ui/expanded_chat_panel.tscn` 参照用户游玩视频 `12_聊天页.png`：使用贴近画面两侧的窄双层金边、暖色纸面、紧凑频道页签、黄色滚动条及带内外描边的木框按钮，去掉原来的粗边和四角纹饰。界面覆盖地图，底部现有输入框继续使用同一份草稿及发送状态；不虚构视频中的传声筒库存。空消息提示置于纸面左上方。
- 共享 `GameWorldScreen` 管理开合按钮：展开时使用同尺寸向下箭头、提示“收起聊天”，再次点击收起；返回、Escape、外侧触摸或代码隐藏窗口后均恢复向上箭头。开合事件分别交由本地/联机控制器处理，保留输入草稿及战斗快捷键恢复逻辑。
- 支持全部、世界、系统筛选；地区、队伍、帮会、私聊保留参考图位置并禁用，提示暂未开放。发送仍使用现有公共频道协议。
- 消息来源为当前世界连接验证后的缓存；没有请求人物上线前的历史。消息与表情通过原纯文本/贴图渲染逻辑显示，任意 BBCode 不会执行。
- 翻阅旧消息时保留滚动位置；在底部时跟随新消息。窗口缓存上限100条，公共消息遵守既有服务端缓存边界，被裁剪消息不会作为新消息重新追加。
- 展开时阻止地图和战斗快捷键穿透；返回、Escape、窗口外点击或触摸均可收起。表情选择使用原输入框，发送确认后才清除草稿，网络未连接或待确认时两处表情入口同时禁用。

验证：

```powershell
& $env:GODOT_BIN --headless --path client res://tests/expanded_chat_test.tscn
```

2026-10-17，Windows / Godot 4.7.1：展开聊天无界面43项、实际渲染46项、本地/联机模式1051项、表情45项、共享界面28项及公共聊天协议48项检查通过。包含通过真实 GUI 事件点击战斗布局下的收起箭头，验证遮罩不会挡住按钮；鼠标事件按窗口最终缩放变换投射，兼容无界面与渲染窗口。已目视检查空消息、长消息滚动和收起状态截图。本次未重新导出或部署 Web 包。

设置 `SSJX_EXPANDED_CHAT_CAPTURE_PATH` 为现有输出目录并以图形模式运行该场景，可生成 `empty_chat.png`、`expanded_chat.png` 与 `collapsed_chat.png`。
