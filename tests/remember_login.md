# 记住账号与登录页

## 2026-10-17 HTTPS 协议错误提示

账号 HTTPRequest 的 TLS 握手失败仍保留 `NETWORK_ERROR` 重试契约，并增加不含凭据的 `transport_error=TLS_HANDSHAKE_ERROR` 分类。登录页明确提示检查协议、端口和证书，HTTP 服务不能填写为 HTTPS。不关闭证书验证、不自动回退 HTTP。

本机 8000 部署提供 HTTP，原生编辑器客户端若保存 `https://127.0.0.1:8000` 会在登录前握手失败。已用实际 Godot 请求复现 TLS 错误，并通过 `http://127.0.0.1:8000` 收到测试用不存在账号的认证拒绝，证实请求到达后端；此检查不创建账号或修改玩家数据。本机连接偏好修正在用户目录，未加入 Git。

验证：登录 UI 51、注册流程 52、角色 UI 69、账号认证 UI 19 项通过。本次不打包、不更新网页部署。

登录页沿用游戏的朱红、米黄、古铜色；朱红主按钮用于登陆，浅金描边按钮用于注册。“记住我”位于密码下方独立行，使用相同色系的勾选图标。布局和状态样式定义在`client/scenes/ui/server_login.tscn`，不由脚本动态搭建。

默认不保存凭据。用户勾选后，仅在登录成功时写入最后一组绑定服务地址的用户名与密码；注册成功后的自动登录也适用。下次打开自动填入，不自动发送登录请求。取消勾选立即清除，退出账号保留记忆；换服清除自动填入的密码，local模式禁用记忆。独立加密文件与本机密钥的限制见[账号设计](../design/auth.md)。令牌、聊天和角色存档不写入凭据文件。
