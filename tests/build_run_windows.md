## 本机运行

数据库使用仓库现有 Compose 配置及持久卷，仅绑定本机；服务读取私有 `.env` 并执行迁移。`GET /readyz` 返回 `status=ok`、`stage=account_auth`，能力列表包含账号、角色、共享地图及聊天。监控页面 HTTP 200。

- 游戏服务器：`http://127.0.0.1:8080`
- 只读监控：`http://127.0.0.1:9090/`
- PostgreSQL：`127.0.0.1:5432`

账号、角色与双端集成测试使用独立的短期数据库容器并在结束后清理，不访问开发数据库。开发服务与开发数据库保留运行，UI 检查已停止。

Cargo 本机使用 USTC sparse 镜像；Docker 命令行拉取镜像成功，代理设置保留在本机。`.env`、Cargo 本地配置、代理环境文件和 PowerShell 代理脚本均被 Git 忽略；本报告不包含密码或代理配置内容。

本轮未运行千人容量、长稳或公网 TLS 验证，不将本机启动和小规模联调解释为容量验收。
