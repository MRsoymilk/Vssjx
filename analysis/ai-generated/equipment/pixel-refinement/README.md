# 原生像素精修输入与产物

2026-10-23。骨甲幽光、冥林异装、初号机共18套的后处理；生产目标为原生部件和32×32图标。使用已有正式素材逐像素整理材质与高光，初号机非武器图标在原生像素格上重新绘制。

- `inputs/`：精修前270张部件与图标，共约402KiB。用于确定性重建，不从已经精修的输出重复调色，不参与客户端导出。
- `baseline.json`：输入路径与SHA256；另记录实际生效的赤翎破军编辑器头部及其两个 `[0,2]` 偏移。该原编辑图片保留在原位置。
- `refinement.json`：已应用的18套、270张正式图与新编辑器覆盖的SHA256，以及生成工具摘要。
- `tools/refine_equipment_pixels.py`：材质色阶、脸部保护和图标像素绘制。所有角色部件保持原始画布／帧／alpha；头部下发和颈部接缝保持原像素。

在仓库根目录执行 `python3 -B tools/refine_equipment_pixels.py` 重建全部正式图；加 `--check` 只在内存重建并核对字节。`--sets boneglow/wzs` 可限定套装。首次加入其他现有套装时使用 `--snapshot` 登记输入；已登记输入不覆盖。

原素材导入器负责原稿拆分，此工具负责精修后处理。正式纹理若包含摘要之外的额外改动，工具会停止，先核对后再决定是否更新精修输入。验证记录见 [`tests/equipment_refinement.md`](../../../../tests/equipment_refinement.md)。
