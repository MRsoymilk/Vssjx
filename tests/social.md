# 社交验证入口

[设计规则](../design/social.md) · [测试总览](testing.md)

```sh
python -X utf8 tests/run_social.py
```

脚本使用独立临时 PostgreSQL，覆盖匿名／越权、公开资料白名单、好友确认／拒绝／冷却／取消／删除、重复操作与冲突、帮派审批／公告／移交／解散、并发入帮、审计失败回滚及重启持久化。

设置 `GODOT_BIN` 时启动真实客户端，检查登录、读取资料、接受好友、创建帮派和公告。`res://tests/social_test.tscn` 覆盖按钮权限、确认、原请求重试、查询排队和本地角色隔离；`SSJX_SOCIAL_CAPTURE` 指定实际渲染截图目录。

使用测试脚本创建的数据库和服务，不连接玩家库。当前契约依赖迁移 `0018_social.sql`，不包含私聊、帮派仓库或帮战。此文件仅整理现有入口，不表示本次已重新执行集成测试。
