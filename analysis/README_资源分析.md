**本次找到的是真实的《蜀山剑侠Online》游戏客户端与美术资源集合，不是以前的冒泡社区通用启动壳。**
主包 MRPG 元数据确认：显示名“蜀山ol”、描述“蜀山剑侠Online”、开发者“博荣无限”、应用 ID `403084`、主包版本 `48`。

## 可运行性与缺失内容

- 本次完成了**静态解析与素材恢复，没有执行不可信的 ARM 本地代码**，无法证明在现有 MRP 模拟器内可登录或进入游戏。
- `start.mr` 可反汇编，引用了 `sdk_key.dat`；该文件**不在此次 ZIP 中**，是否可以通过平台环境生成或跳过，需要运行时分析。
- 游戏 `gameonline.ext` 为编译的 ARM 原生代码；这里不等同于获得完整 C/C++ 源码。
- `record(205741974)/` 和 `hero/` 为**空目录**，无可恢复的旧玩家角色数据。
- 地图图块与图片恢复并不保证地图逻辑、场景索引、NPC 行为以及服务器业务数据全部齐全。
- `cover.str` 中有“游戏试玩”菜单，但还未证实它是否能脱离原服务器独立使用。
- 没有发现已经恢复的游戏服务端程序、账号数据库或可用的官方游戏服务器。

## 输出文件与使用方式

原始ANI层、序列和未解释尾部现在按资源保存于`animations/<分类>/<名称>.json`，共310份，由`animations/index.json`索引；数据语义不变。运行时33份烘焙角色元数据另存于`../client/assets/data/actors/`并按需加载，本目录的分析编排不随Godot项目打包。两类文件均由`../tools/import_assets.py`生成，勿把分析原始编排当作运行时角色清单。

1. 打开 `index.html` 可**完全离线**浏览所有解码的 PNG（可搜索文件名／筛选模块）。
2. `preview_original_assets.png` 为精简拼图预览。
3. `decoded_png/` 按主程序、地图、英雄、怪物、物品、特效分类保存 **3,300 张** PNG；多帧精灵名带 `_frame000`。
4. `decoded_text/` 为原始 `.str` 恢复的 UTF-8 文案。
5. `unpacked/` 为 **1,916 个原始内部成员**（已经从包成员的 gzip 压缩解开；此处包含头部元数据 JSON）。
6. `source/` 是 ZIP 内原始 6 个 MRP 程序／资源包及 `commonRecord/version`。
7. `decode_assets.py`、`unpack_mrp.py` 是可复现的静态提取脚本（需要 Python、NumPy、Pillow）。
8. `disasm/start.mr.asm` 是脚本字节码指令反汇编，不是高级源代码。
9. `image_manifest.json` 列出每张 PNG 对应的原始文件、帧号和尺寸。

**保留原始 ZIP 文件，用于将来试验模拟器和恢复网络功能。不要直接执行未知来源的 ARM 代码。**
