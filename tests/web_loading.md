# 网页加载停顿修正（2026-10-17）

用户手机截图停留在网页引擎加载页。原加载页只有进度条，没有字节数、停顿说明或失败后的重试入口。此前实际公网浏览器测试等待 90 秒仍在下载阶段，不据此声称手机必然是同一原因。

公网 HEAD 诊断：原引擎约 39.5 MB、PCK 约 16.2 MB，均为 `CF-Cache-Status: DYNAMIC`；引擎由 Cloudflare 向浏览器压缩为 zstd，但源站未提供压缩，PCK 没有内容编码。当前电脑上行较慢，不能将所有加载停顿仅归因于终端设备。

本轮导出、部署：

- 网页加载页增加已加载大小／总大小、未知总量动画、下载完成后的初始化状态；20 秒无进度时解释停顿并允许手动刷新。网络恢复时继续同一次加载；失败后重载页面，不在同一页面重复初始化引擎。重新加载不清除本站存档。
- 版本目录 `assets/ef28b8f18e3a27b2/` 固定这次引擎、脚本与资源内容。根 HTML 不使用长期缓存，版本目录使用 immutable，旧根目录链接仍可访问。
- 本轮 WASM 源站 gzip 从 39,514,754 字节减为 10,054,758 字节；PCK 从 16,221,656 字节减为 15,451,212 字节。两者合计由约 55.7 MB 降至 25.5 MB。没有承诺所有手机的实际加载时长。
- 当前 `SSJX_WEB_ROOT` 改为忽略目录 `work/builds/web-loading-20261017/public`，同时保留之前导出目录及本地配置备份 `work/web-loader-fix/web-deploy.before.env`。带两个 Compose 配置更新网页容器，游戏进程和数据库未重启。
- 公网已确认新加载页、版本化 URL、gzip 与长期缓存响应头；但 Cloudflare 状态仍是 DYNAMIC。域名后台尚未添加静态目录缓存规则，不能声称 CDN 加速已生效。操作方式在 `deploy/WEB.md`。
