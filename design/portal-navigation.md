# 江湖驿站导航与游戏子路径

[返回设计索引](README.md) · [切换操作说明](../deploy/PORTAL.md) · [验证记录](../tests/portal_navigation.md)

性质：**已实现的本地候选页面与兼容路由，尚未切换公网**。不重新导出游戏，不增加账号接口、论坛服务或数据库迁移。

## 页面设计

导航使用墨绿底色、米白标题、古金边框及朱红游戏主按钮，复用现有 AI 女性剑侠图标。桌面展示双列卡片，手机改为单列，保留键盘跳过导航、明确焦点和减少动态效果。

- 门户以游戏项目为主体，不以网页为默认平台。“开始游戏”和顶部“游戏”定位到同一游戏条目，在该条目内并列选择网页游玩或 Android 预览版；首次访问导航不加载游戏引擎。
- “剑侠茶馆”作为论坛预留卡片，按钮禁用并注明筹备中；不放失效论坛链接或自动安装 Flarum。
- Android 下载与网页入口共用一张游戏卡片，不另设独立下载条目。下载沿用 `/downloads/vssjx-arm64.apk`，不暗示 APK 已同步最新代码。
- 源码、游玩指南和来源许可指向实际 GitHub 仓库；正式启用前确认对应文档已经发布到所链接分支。
- 页面没有 JavaScript、登录表单、第三方字体、统计脚本或资源预取，不读取本地存档及账号状态，不展示虚构在线人数。

`tools/prepare_portal.py` 从 `deploy/portal/` 准备 HTML、CSS 和原图缩小得到的 WebP，拒绝覆盖非空输出，不修改游戏图标和导出包。输出只是导航静态文件，不是新的游戏安装包。

## 路由与兼容

| 路径 | 行为 |
|---|---|
| `/` | 存在 `navigation/index.html` 时显示导航，否则继续原游戏首页 |
| `/navigation.html` | 导航预览入口，未准备导航时返回 404 |
| `/navigation/…` | 三份导航静态文件，禁止缓存为 immutable |
| `/webgame` | 临时跳转到带尾斜杠的 `/webgame/`，保留查询参数 |
| `/webgame/` 与其资源 | 使用原导出目录，按子路径读取相同游戏文件 |
| `/index.html`、`/assets/…`、引擎文件 | 继续提供旧文件，兼容旧链接及已经打开的页面 |
| `/api/v1/` | 原样转发游戏服务，保留授权、Origin 与 WebSocket 升级 |
| `/downloads/…` | 沿用原静态目录中的 APK 文件 |
| `/flarum`、`/flarum/…` | 明确保留为 404，直至独立论坛服务经授权接入 |

兼容路径仅在公网 `public.web.https.nginx.conf` 接入，不自动改变独立本机／LAN 网页 Compose 的部署方式。原静态挂载、游戏进程、数据库和证书不变，不通过新增挂载强迫重建代理容器。

## 切换与回退约束

先在导航文件尚不存在时加载新路由，确认原首页和新游戏入口同时有效，再完整安装导航目录。保留游戏 `index.html` 和旧版本资源，不把导航 HTML 覆盖到游戏首页文件。

导航目录在同一文件系统完整准备后切换到 `navigation/`；不要直接在已生效目录中逐文件生成，以免短暂出现缺图或缺样式。临时移出导航目录即可让根路径回到原游戏，无须回退数据库。

当前单文件 bind mount 可能仍持有旧 inode，远程更换仓库文件后不能假设容器看到新配置；须核对实际挂载内容、备份、验证 `nginx -t`，再以安全方式写回已挂载文件并平滑 reload。不能在未核对时执行 `up --force-recreate`、停止游戏服务或操作数据卷。

## 存储与论坛边界

当前浏览器存储适配使用固定数据库 `vssjx-offline-v1`，联机配置取 `window.location.origin`。只变更页面路径时不改变这两个契约，API 仍在 `/api/v1/`，Origin 白名单不加页面路径。真实远程包版本、运行与保存恢复仍需切换前核验，不清理网站数据。

论坛和游戏位于同源时，路径不是浏览器安全隔离；未来 Flarum 插件、上传及 XSS 风险需单独管理。接入论坛不意味着账号自动互通，也不能共用游戏表或授予论坛游戏数据库权限。

## 验证入口

[静态与实际浏览器检查](../tests/portal_navigation.md)覆盖布局、无自动游戏请求和同源存档适配；隔离 Nginx／TLS 检查覆盖旧／新资源、MIME、gzip、缓存、401、隐藏路径、下载与平滑重载后原有 WSS 连接。测试使用惰性文件和协议夹具，不冒充真实 Godot、生产玩家或论坛验收。
