# local 单人入口

服务地址填写 `local`（忽略大小写及首尾空格），保存后点击“进入游戏”。不需要用户名、密码或注册，不发起服务发现、账号或世界连接请求；线上登录会话保持独立。

进入本地游戏会取消未完成的账号请求，并暂停账号的后台自动刷新；内存中的线上账号数据仍独立保留，重新选择服务器并点击登陆后恢复网络处理。

两种情况都先进入角色选择页，并显示“本地模式”。没有存档时显示空槽，通过菜单创建角色；创建成功后回到角色选择，明确点击“进入”才启动地图。已有存档时读取现有角色供选择。沿用本地自动保存、任务/战斗结算保存和退出保存，记录角色属性、物品、任务、签名及位置。损坏存档显示错误并保留原文件，不能静默覆盖。

点击底栏社交按钮打开本地聊天，消息只有自己可见，不进入公共频道；聊天记录仅保存在本次游玩的内存中，返回封面后清空。详见 [模式隔离与共用地图](game_modes.md)。

```sh
godot --headless --path client res://tests/local_mode_test.tscn
```

测试使用独立存档及连接设置。跨进程验证可为两个独立Godot进程设置相同的 `SSJX_LOCAL_TEST_PATH`，先以 `SSJX_LOCAL_TEST_PHASE=write` 运行，再以 `read` 运行；读取阶段结束清理测试文件。
