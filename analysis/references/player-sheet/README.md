# 用户提供的蜀山剑侠资料表

原始文件为用户提供的 `蜀山剑侠怪物数据-工作表1.csv`，已逐字节保存为 [source.csv](source.csv)。来源作者、游戏版本与采集方式尚未知，定位为**待核对的补充资料**，不当作原服网络记录或反编译源码。归档工具的输出仅写入 `analysis`。用户随后授权“接入技能”，具名技能已另行生成运行时目录，所用临时规则见 [技能接入说明](../../../design/skills.md)；此处原始记录仍保持未知字段为空。

这份表对技能恢复有直接帮助：提供 30 个具名技能的职业／门派归属及效果描述，另有 18 行技能信息仍缺名称。它补充了之前缺少的招式名称，例如仙人指路、雷霆一击、沧海明月、万剑归宗、起死回生、偷天换日等；仍缺原始 ID、各级灵力消耗、伤害／治疗公式及动画映射。

## 归档内容

| 文件 | 内容 | 数量 |
|---|---|---:|
| [manifest.json](manifest.json) | 来源摘要、SHA256、统计、核对与限制 | 1 |
| [maps.json](maps.json) | 地图名称、NPC 原文、同区怪物格、原包名称核对 | 214 |
| [monsters.json](monsters.json) | 怪物格原文、可识别的等级、所在地图 | 147 |
| [skills.json](skills.json) | 职业／门派、技能名、等级列原值、描述及备注 | 48 行，30 具名、18 缺名 |
| [items.json](items.json) | 道具名称、等级、用途及绑定标记原文 | 50 |
| [materials.json](materials.json) | 材料列与药材列分别保留 | 21 |
| [gems.json](gems.json) | 宝石名称与属性原文 | 43 |
| [equipment.json](equipment.json) | 普通装备 10 项、传说装备 30 项 | 40 |

147 是非空怪物格数量，不是经过去重及身份核验后的怪物种类数。表内共有 36 个非空 NPC 格，一个格内可能包含多名 NPC，不能将其统计为 36 个 NPC。

## 已核对与待核对

- 地图使用原包 `analysis/catalogs/online_world.json` 对照：211 个名称完全相同，另三个名称去掉尾部 `(20-30级)`／`(51-60级)` 后与原包相同，合计 214 个对应。只证明地图名称及同序位置一致，不证明其余记录全部正确。
- 表内 `[0]` 等序号对应原包名称表索引，不是原服地图 ID。例如灵空台的表序号为 0，原包地图 ID 为 1。两个字段分开保存。
- CSV 是多张独立表横向并排。技能、道具、材料、宝石、装备不与同一行的地图建立关联，不能据此推定掉落地、学习 NPC 或获得地点。
- 右侧材料、宝石、装备表在 CSV 第二行已开始填数据，不能把这一整行当表头丢掉。一级铁矿、茯苓、一级敏捷石、孽龙锤已保留。
- 技能列名是“技能等级”，但值为 5、15、25 等，其实际含义尚需确认。当前不转成技能阶数或已确认学习条件。
- “花间派”按用户表保留，暂不自动改成当前重建角色中的“花涧”。“仗／杖”、“xx”、“什么”、“有个”等表内字样不擅自纠正或补全。
- 宝石的 `8-`、`16-` 等值和升级概率说明保留原文，未生成已确认的数值规则。
- 技能、怪物和装备的原始 ID、图片／动画映射、缺失公式继续为空。参考记录用行号定位，与原包解析出的身份分开。

每条分类记录均带 `source_row` 和 `source_columns`，可回到原始 CSV 审核。来源信息和统计见 `manifest.json`。重新生成：

```sh
python tools/import_player_reference.py
python tests/test_player_reference.py
```

原生技能数据流解析的独立进度见 [技能恢复记录](../../recovery/skills/README.md)。这份用户表不改变“尚未找到原服技能下发记录”的结论，但可用于后续核对招式名和描述。
