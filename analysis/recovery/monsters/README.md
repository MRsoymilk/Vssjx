# 怪物动画全量检查

运行 `python tools/audit_monster_animations.py`，报告保存到
`client/assets/admin/monsters/animation_audit.json`，管理页每个原包怪物的「动画检查」中可查阅。

本轮覆盖 `ssjx/monster.mrp` 的全部 **117 份 ANI、142 份图像成员、3133 个合成帧、969 组序列**。
核对原包、ANI、图像成员、图集的 SHA256，原始图层和序列归档、引用图片、变换编号、
帧引用、时长、图集尺寸及 PNG 完整性。当前结构检查错误数为 0。

原始观测：46 份 ANI 含 `tx38` 星形层，98 份的某些序列具有不同身体标志变换，
77 份的某些完整可跟踪序列有超过 4 像素的横向位移。
这些是原始动作数据的现象，**不代表 46 / 98 / 77 个错误**：星形层也可用于发射攻击，
原客户端的转身和位移可以合理存在。没有统一删除星形、刀光、火焰等特效。
部分怪物换身体切片、旋转或缺少统一身体标志，报告明确记录跟踪覆盖率，
不会用不完整标志的位移跨度断言动作稳定。

## 当前游戏中的四组怪物

`langw`、`xt1`、`hs1`、`nt1`（对应目前 6 个敌人配置）全部检查：

- 保持身体横向锚点、面向一致；世界／战斗决定整个人物的移动与朝向。
- 待机、行走循环不包含战斗特效。修复 `hs1` 循环星形层、`nt1` 待机冲刺光效。
- 攻击与受击采用不同合成帧、非循环播放，实际扣血后先受击再进行反击。
- `langw` 保留已核对的受击星形姿势；其攻击使用不含受击星形的派生帧。
- 另三组尚未核实原版独立受击序列，使用独立中性姿势停留 0.3 秒，配合已有战斗
  命中特效。这是重建表现，**没有将原始序列猜测标注为受击**。
- `xt1` 攻击刀光、`hs1` 拳击星形／弹道、`nt1` 攻击冲刺光效完整保留。

派生帧记录来源帧与排除图层；原始 ANI、`analysis/animations/monster`、管理页原包图集及
`source_N` 序列保持不变。管理页「已接入」条目的命名动作是修正后的运行时版本；
「原包资源」条目的 `source_N` 是未指定动作语义的原始序列，不是校正后的攻击或受击。
