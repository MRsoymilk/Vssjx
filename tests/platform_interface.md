# P1 平台接口基础：原生配置与存储

对应[平台方案](../design/platform_interface.md)的P1首个实施单元（P1a），不是P1～P4全部完成声明。

后续P1b已接入原生资源准备，契约、取消/并发检查和新验证记录见[platform_resources.md](platform_resources.md)；下方P1a结果仍对应当时范围，不改写为后续源码的验收记录。

后续P1c的输入焦点、组合状态提交检查与原生退出请求见[platform_input_actions.md](platform_input_actions.md)。

## 本阶段契约

- `Platform`入口显式区分未初始化、初始化中、就绪、降级与失败；`when_ready()`可等待，初始化幂等。当前原生适配器同步就绪，尚无降级路径。未实现的Web目标明确失败，不冒充原生成功。
- `Game`在平台就绪后取得存档路径，并提供自己的就绪结果；主页面等待平台和Game配置完成。账号请求在平台未就绪时返回`PLATFORM_NOT_READY`，不发送凭据。失败有可读说明，不是黑屏。
- 工厂、上下文与接口不依赖游戏单例、网络或具体场景；上下文能力快照与显示/生命周期动态状态分开。
- P1a只建立已有实际接入需求的配置、存储、显示和生命周期契约及原生实现；资源准备在P1b补入，输入及系统退出请求在P1c接入，不提前建立无调用方的空壳。
- 配置接口只接受`save`和`connection`两个命名项。保留原生显式路径优先于`SSJX_SAVE_PATH`/`SSJX_CONNECTION_PATH`，再使用原默认路径的顺序；服务器地址规范化仍由原业务模块共享，接口层不读取服务端`.env`。
- 存储结果区分成功、不支持、拒绝、暂时失败、取消、数据无效；各调用按实际情况返回稳定代码和说明。基础契约不支持的方法不能静默返回成功。
- 原生存档和地址配置仍同步返回结果，不在本阶段偷换为浏览器异步持久化。写入完成表示本地文件flush及同目录rename完成（`native_file`回执），不承诺断电安全、备份、浏览器同步或永久不被清理。
- 读取有大小上限（存档1MiB、连接配置64KiB）；旧v1 JSON、默认路径、可选字段兼容和ConfigFile格式保持原样。读错、损坏、超限或写入失败不能修改当前角色或覆盖原文件。
- 显示接口报告原生窗口像素、屏幕可用区、安全区和Godot逻辑区，提供窗口/逻辑坐标换算，不修改320×480画布或admin的独立窗口策略。此处不是CSS/手机安全区实现。
- 生命周期只上报并去重焦点、挂起和恢复事件；本阶段不自动保存、重连、延长服务端超时或修改角色。

## 自动化入口

```sh
python -m unittest discover -s tests -p 'test_*.py'
python tests/run_platform_interface.py --output /tmp/opencode/vssjx-platform-p1
python tests/run_platform_interface.py --render --network --output /tmp/opencode/vssjx-platform-p1
```

`--render`需要Xvfb与可用的OpenGL，环境变量沿用[testing.md](testing.md)。执行器复制不含`.godot/`的客户端工程及旁侧`shared/`协议夹具，在独立配置、缓存、用户数据和存档中运行，不触碰玩家数据或当前编辑器缓存；不继承开发者的`SSJX_*`端点、秘密、截图路径或测试阶段变量。未提交的admin修正不是本单元提交范围。

检查内容：

1. 原生选择、显式就绪、重复初始化、不支持目标、失败页面和未就绪请求防护。
2. 配置优先级、未知项拒绝、地址规范化、旧JSON/ConfigFile兼容、离线/在线数据隔离。
3. UTF-8读写、原子替换、写入/替换失败、大小上限、损坏文件保留及临时文件清理。
4. 两种窗口比例的坐标换算、尺寸信号、生命周期事件映射和去重、不修改业务状态。
5. 现有游戏整流程、地图输入、离线模式、菜单、选择角色、世界增量与公共聊天等回归。
6. 回环HTTP协议夹具执行注册、登录和角色流程（非真实数据库验收）；可选真实Rust服务发现、异常响应及跨进程地址保存。
7. 可选真实渲染的接口测试及原游戏页面截图；原生Linux运行不代表Windows、Web或手机浏览器通过。

## 后续关口

- P1七类接口已有原生基础接入，额外能力随实际需求补充；Windows原生回归待相应环境验收。
- P2仍需受控同域服务地址、单线程Web模板、存储异步契约及全部调用方提示迁移、资源准备和精确Origin白名单。当前不能宣称网页联机可用。
- 既有`RememberedLogin`含本地加密密码及同设备密钥，**未在本阶段迁移或新增到平台存储**。这与设计的浏览器不持久化凭据边界存在冲突风险；P2必须阻止Web复用该路径，并核对登录页面及公开包中所有凭据来源。本阶段不删除已有玩家文件或擅改原生登录功能。
- P3/P4的手机输入、安全区、页面回收、持久化风险及真实设备支持名单均未验收。D07/D08发布关口不变。
