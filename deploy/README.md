当前世界仅支持**一个游戏写进程**。多个进程连接同一数据库不构成世界集群；网页代理、容器健康和配置的人数上限也不代表容量验收。

## 部署前检查

- 按 [.env.sample.txt](../.env.sample.txt) 和场景样例配置私有环境，不覆盖已有密码或数据卷。
- 备份数据库并在隔离环境验证恢复、迁移、协议与共享配置兼容；数据库回退不能只靠切换旧镜像。
- 按候选提交执行完整迁移集；经济托管、绑定、技能熟练度和无尽榜单均须配套客户端。已有拍卖、退款、交易及在途战斗不能由旧程序忽略或覆盖，详见[近期迁移](../server/README.md#近期功能与迁移兼容)。
- 公网账号入口使用有效证书的 HTTPS／WSS，配置准确的浏览器 Origin 白名单。
- 数据库、8080 游戏监听和 9090 管理页面不直接公开；只发布必要的代理入口。
- 网页静态根目录仅包含导出产物，不指向仓库、`analysis/`、`work/` 或配置目录。
- 核验 [素材许可](../docs/asset-provenance.md) 与开源义务，不把一次部署记录当作持续运营或全平台支持承诺。

构建、推送、部署和数据库迁移属于独立操作，阅读指南不意味着应立即执行。历史事实见 [发布基线](../tests/release_20261018.md) 和 [后续聊天更新](../tests/chat_moderation.md)，当前源码能力与这些发布版本可能不同。
