# 公共聊天 chat-v1（已实现）

[返回设计索引](README.md) · [共享地图](shared_world.md) · [服务端管理](../server/README.md)

性质：**当前实现契约**。基础公共聊天之外已接入表情、系统通知与管理撤回，相关记录见文末。

## 范围

认证并进入世界的角色才能读写 `public`；身份、昵称、消息 ID 和时间由服务器生成。频道跨地图且独立于地图订阅。聊天正文仅保留于有界内存缓存，不持久化到数据库、日志或本地存档；管理审计单独记录处理信息，不保存被处理正文，长期留存策略仍需明确。

`chat.send` 字段仅 `client_message_id`（UUIDv4）、`channel="public"`、`text`，见 `shared/protocol/chat-send.schema.json`。输入最多120个Unicode标量/480字节（规范化前检查），仅去除首尾ASCII空格。拒绝全空白、Unicode控制字符、U+200B～200F、U+2028～202E、U+2060～206F和U+FEFF。标记、URL和HTML均只作普通文字显示，无链接执行、富文本解析或昵称解析。

## 去重、排队与限流

去重键是 `(character_id, client_message_id)`，同ID需相同规范化文本/频道。已受理请求先查短期回执，后查新操作禁言和配额；同ID改内容返回 `CHAT_ID_CONFLICT`。`chat.result`包含原ID和状态：

- `QUEUED`：已进入有界公平队列，但还不是已发送。
- `SENT`：已进入频道历史，包含原 `message_id`；不承诺所有用户已经显示。
- `REJECTED`：含明确错误码，无新消息入队。界面保留输入，可由用户决定新操作。

每角色最多一个排队消息，队列按角色先到先服务；发送完的角色再发只能排到队尾。个人令牌桶默认突发3条、5秒恢复3条，跨连接/离开继续生效。频道默认20条/秒，空闲预算最多积累1秒，避免停顿后无限突发。队列满、去重表满时新操作明确拒绝，不逐出仍有效的回执后再次发送。队列、回执、限流身份表、历史和客户端缓存均有上限。

默认受理回执至少保留发送后300秒，跨重连和显式离开有效；进程重启不保留。客户端仅保留一个待确认消息，未知结果在同channel_epoch/期限内至多原ID重试3次，绝不换ID自动再发；确认窗口过期或服务重启时标明结果未知、不自动发送。每条消息最多一次频道广播，但不宣称跨服务重启的持久化exactly-once。

## 独立序列与历史

`chat.ready`公开channel_epoch（每服务进程随机UUID）、latest_seq、oldest_seq、history_limit、dedup_seconds和字数/字节上限。只有通过票据认证后才发送。latest_seq为频道最新序号；oldest_seq为当前角色可读取的起点，取上线起点与频道保留窗口起点的较大值；无可读消息时为latest_seq+1。

`chat.batch`每批最多16条，包含channel_epoch和messages；消息含seq、message_id、sender_character_id、display_name、server_time_ms、channel、text。seq与时间为十进制字符串。聊天不使用世界快照stream_id/seq，不插入快照块中间。

默认只保留最近50条。角色首次进入世界时，在插入角色的同一把世界锁内记录频道最新序号，只接收此后发布的聊天；同步世界快照期间发布的消息也会收到。短暂断线、同一游戏会话重连沿用原上线起点；显式离开、保留角色过期或新游戏会话重新记录起点，不读取上线以前的历史。客户端清空旧显示缓存后安装，批内先完整校验再追加。游标落后被历史窗口截断时先发`chat.gap`，再从新oldest_seq继续，不承诺完整补发。客户端同样最多保留握手指定的历史数量。慢连接受现有发送超时保护，不为每连接创建无限广播队列。

## 禁言与界面

迁移 `0005` 增加 `accounts.chat_muted_until`，由数据库时间判断禁言，覆盖账号全部角色。本机管理页 `/chat` 已支持筛选、删除消息、禁言及解除，要求原因、操作号与同源保护，不公开到游戏代理入口。删除同步撤回客户端原文，审计不保存正文；相关竞态和已排队消息处理见 [聊天管理](../tests/chat_moderation.md)。

地图底部“聊天”打开可收起面板。面板不会暂停网络或远端玩家，只阻止本人地图键盘/点击输入；打开时请求停步。输入WASD/回车仅作聊天编辑/发送，服务器确认后清空输入，排队期间禁止编辑原内容。

配置从 `.env`／进程环境读取，见 `.env.sample.txt` 的 `SSJX_CHAT_*`。相关入口：[公共聊天](../tests/public_chat.md)、[表情](../tests/chat_emotes.md)、[展开面板](../tests/expanded_chat.md)、[管理与发布](../tests/chat_moderation.md)。历史发布不等于当前全部源码或混合负载已验收。

内嵌输入栏的输入框、表情、发送控件在 `game_world_screen.tscn` 中统一底部锚定，逻辑高度23像素，底边距5像素，文本历史与编辑区留2像素间距；字体最小高度变化时向上增长，避免压住面板底线。展开／收起按钮保持22×22，图标16×16居中；箭头SVG按32×32导入，仅按钮采用线性过滤，减少窗口放大后的阶梯感，地图与其他像素素材继续保持原采样方式。普通地图与战斗共用该布局。
