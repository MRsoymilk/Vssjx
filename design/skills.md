# 技能接入与待恢复字段

[返回设计索引](README.md) · [NPC 入派](school-membership.md) · [组队战斗](teams.md)

性质：**当前实现规则与资料缺项**。具名技能、显式重建公式及原版未知字段分开维护；角色门派暂不限制职业技能。

用户授权接入其提供资料中的技能。当前运行时目录 `client/assets/data/skills-v1.json` 共37项：原资料30个具名技能、后续新增石破天惊／横扫千军／清风荣新／双龙戏珠，以及三个旧入门兼容技能。18条原始缺名记录仍留在analysis，不因后续明确新增技能而填造原名或原始ID。使用 `python tools/build_skill_catalog.py` 从归档资料与显式新增规则生成目录。

名称、职业／门派归属、效果文字来自 `analysis/references/player-sheet/source.csv`，每项保留行号。它是玩家提供的补充资料，不是已恢复的原服技能下发表。原生技能解析结果与证据仍见 `analysis/recovery/skills/README.md`。

## 当前规则（2026-10-27）

- 角色职业／等级决定解锁，门派暂不限制技能；主动技能使用目录 `mp_cost` 固定扣灵力，被动为0，不随最大灵力按比例增加。全部主动技能当前无回合冷却，可连续施放；状态持续、控制保护、指令确认和战斗总回合上限保留。见[固定消耗](../tests/fixed_skill_costs.md)及[技能效果调整](../tests/skill_rebalance.md)。
- 主动技能每20次有效施放升1级，从1级至15级需280次；被动不累计。技能等级只改变资源阶段，不额外加伤害。1～5级基础、6～9级资源1、10～14级资源2、15级资源3；23项配置阶段资源，详见[熟练度与阶段](../tests/skill_proficiency.md)。
- 本地独立存档、联机服务端计数；群攻只计一次，未执行、控制失效、非法指令或重复回执不计数。迁移0042保存角色熟练度，旧记录缺字段按1级；技能书与战斗选择器显示当前等级、解锁条件和资源阶段，不存在虚构的技能点购买升级。
- 力士主动／被动物反、法反按自身物攻100%计算，对应受击类型生效；主动持续2回合，与被动取高不相加。侠客混元入蛊的首击及每轮固定毒伤不可反弹，每轮毒伤为施法者物攻100%；万剑归宗每目标300%威力、该技能独立70%暴击概率。隐者起死回生／救死扶伤立即恢复施法者当前攻击力100%的气血，后者作用于全部存活队友，不复活亡者。上述特殊规则不代表其他技能绕过防御／PvP预算。
- 双龙戏珠最多选两个存活敌人，优先选中目标；排山倒海等全体技能仍覆盖全部存活目标。同名技能不重复创建。完整倍率、目标、状态与例外以共享目录、双端规则和[效果验收](../tests/skill_rebalance.md)为准。
- 指定力士／侠客技能和隐者主动技能原地施法，部分侠客技能逐目标发出飞行特效，到达后才播放命中；本地、联机和决斗共用动作选择。动作／轨迹不改变费用、伤害或熟练度，详见[施法表现](../tests/battle_casting.md#原地施法与飞行特效2026-10-27)。

后文带日期的眩晕及早期公式保留接入背景；其旧冷却、反伤和百分比消耗不能覆盖以上当前规则，也不能用历史向量数量代替当前完整验收。

## 使用方式

### 雷霆一击眩晕（2026-10-23）

力士通用技能「雷霆一击」5级解锁，新增命中后35%概率眩晕：跳过目标下一次行动，受击不解除。2026-10-23接入时曾设3回合冷却，现已随主动技能统一取消；控制保护仍保留。与睡眠／封印共享控制保护，未命中不施加状态。眩晕按行动消费，不在回合末递减，避免后手施加时提前失效。当前首领与精英遵循相同控制保护，不新增永久免疫。

技能表以 `stun` 附加配置表达，不把该技能归入会降低伤害倍率的通用控制技能类别。它是用户授权的新玩法，不冒充原版规则。新战斗冻结 `balance.stun_revision=1`，旧在途战斗缺字段保留原行为，重连／重启不重新抽取已提交结果。正常本地、联机阵列（单人／组队）及切磋已接入，旧 `solo-v1` 协议入口保留原规则。验证与兼容细节见 [眩晕测试](../tests/stun.md)。

状态条新增金色星环图标，提示“跳过下一次行动，受击不解除”；跳过时播放原地待机及提示，不伪造攻击动作。技能页／选择列表显示当前规则；旧在途冷却值不再阻止施放，原状态按兼容规则处理。图像取自原包 `t14`，与眩晕的绑定是新增语义适配。

- 本地、联机战斗的“技能”打开同一套武功列表，显示名称、灵力消耗及效果，点击技能行或回车直接施展。增益在自身位置施展；攻击沿用已恢复的角色动作，尚无逐技能原版动画映射。
- 两种模式按 `skill-effects-v1.json` 的逐技能人工配置播放原包一次性特效，当前有37个基础条目及69个阶段条目；不再按职业复用同一特效。剑、雷、火、冰、治疗、屏障、催眠、毒雾及摄灵按名称／效果设计，可组合多层并分别跟随施法者或目标。物理／法术反伤心法在对应反伤事件触发。用户已授权这种语义映射，它不是原服绑定恢复成果；[逐项对应表](../analysis/recovery/skills/effect-mapping.md) 列出资源、视觉依据和触发方式。
- 特效随对象进退，但不继承角色镜像或缩放。播放完毕、对象消失、退出战斗或联机断开都会清理。进入战斗时只预备当前角色已解锁技能所需的图像与序列，不一次性加载全部特效；重新导入资源会保留映射中的 ANI。
- 本地技能在原生出招命中时开始播放对应特效及音效；角色出招动作和本次技能的全部特效层结束后，才进入怪物反击。按照特效实际生命周期等待，不追加固定停顿，不等待音频尾音；退出战斗立即取消等待，防止旧回合继续反击。技能费用、冷却与回合末持续效果仍按既有规则结算。
- 人物属性的“武功／心法”按职业展示全部已收录具名技能，不限制角色门派，标明解锁条件；自动反弹归入被动心法，不消耗行动和灵力。
- 人物技能页沿用原包布局与独立说明／灵力区，显示本项目实际熟练度和阶段。原作的技能点消费／学习NPC规则尚未恢复，不将当前有效施放成长当作原版升级机制；[界面证据](../analysis/recovery/skills/interface.md)区分原生依据与当前适配。
- 武功／心法页选中行在常态、悬浮、按下和焦点状态均保留深红底色；不再弹出遮挡列表的阶数提示。页脚显示当前等级和实际已解锁数量，说明区显示所选技能的可用等级。
- 按用户当前要求，门派暂不影响技能：峨眉／花涧／昆仑／闲云野鹤均使用本职业已解锁技能，仍校验职业、等级、主动性和灵力。本地、联机、武功／心法页与战斗选择保持一致；具体已解锁数量由当前目录计算，不沿用新增技能前的固定数量。技能原始门派字段保留为资料归属，不改名、不伪造缺失技能。
- `skill-reference-coverage.json` 继续保留原表18条缺名记录的可复核元数据，不改变战斗目录及其哈希；技能页不再用本门派缺项遮挡职业技能列表。缺项如下：

| 原表职业／门派 | 缺名等级 |
|---|---|
| 峨眉侠客 | 15、25、35、45、55 |
| 峨眉力士 | 25、45、55 |
| 峨眉隐者 | 35、55 |
| 花间侠客 | 35、45、55 |
| 花间隐者 | 25、55 |
| 昆仑隐者 | 25、45、55 |

- 目录等级列为角色解锁等级，自动解锁，与1～15级熟练度分开。本地、联机角色上限60；属性点预算每级5点，最高300。没有已恢复的技能点消费、学习NPC或付费升级表，不实现虚构的升级按钮。
- 新角色先以“闲云野鹤”身份出生，可通过清微道人正式入派，门派身份暂不限制技能；按用户要求，已有角色也进行一次性入派重置，等级、物品与任务保留。[入派流程与迁移](school-membership.md)。
- 原文“花间”在运行时暂对应现有“花涧”门派，analysis 原文不变。`sheet_行号` 是本项目引用 ID，不是原版 ID。

## 初次接入的重建数值（历史）

原表缺失消耗和公式，初次接入曾用 `t = (解锁等级 - 5) / 10`（向下取整）、`9 + 3t`灵力和 `攻击 × (180 + 10t)% - 敌防御`。下表只保留早期重建背景，不是当前主战斗计算；后续平衡内核、固定费用、熟练度和效果覆写以本页当前规则及共享配置为准，所有规则均不冒充原服公式。

| 效果 | 早期接入规则 |
|---|---|
| 流血、中毒 | 每次我方行动后，按攻击的 20% 结算；原文指定 1／2 回合，未指定则暂用 2 回合 |
| 睡眠 | 35% 概率，持续 2 回合，跳过敌方行动及动画；之后的直接攻击会唤醒 |
| 沉默 | 表内 15% 概率，暂持续 2 回合；不阻止普通攻击 |
| 回复生命 | 按最大气血的 15%，结算 2 次 |
| 防御加成 | 暂减伤 25%，持续 2 回合 |
| 暴击加成 | 暂增加 25% 暴击机会，暴击伤害 150%，持续 2 回合 |
| 主动物反／法反 | 对对应伤害类型反弹 30%，持续 2 回合 |
| 被动物反／法反 | 对对应伤害类型反弹 20%，不与同类主动反伤相加，取高值 |
| 偷取灵力 | 最多偷取 20，受敌方剩余灵力和自身最大灵力约束；临时敌方灵力池为 `30 + 等级 × 2` |

早期仅单怪／物理普通攻击；当前单人阵列与组队已支持多目标，怪物包含物理／法术及强力招式，详见[怪物规则](monster-combat.md)。状态时钟和特殊毒伤按当前完整回合规则结算，不能沿用早期单怪描述推断法反没有触发机会。

## 联机与兼容

双方共用版本化目录，并核对 SHA256。客户端只发送技能 ID、战斗 ID、预期回合版本和操作 UUID；服务端重新核对职业、等级、主动性和灵力，门派不参与技能权限判断，独立计算结果。拒绝的行动不扣资源、不推进回合。状态、消耗、奖励和幂等回执在同一数据库事务中提交；持续状态可随重连和进程重启恢复。旧遭遇战在有效行动时重新计算职业被动心法，保留原有持续效果；拒绝行动仍不修改状态。

旧客户端省略技能 ID 时使用三个入门技能；兼容范围限于旧客户端支持的等级，超过 50 级须更新客户端。未协商技能能力时仍走兼容入口。权限策略与目录变更需要客户端和服务端配套发布，仅更新界面不能绕过旧服务校验。基础技能迁移为 `0014`，后续入派迁移为 `0016`；部署应执行候选源码完整迁移集，不手工跳过或改写历史迁移。

## 验证

`tests/test_skill_catalog.py`校验目录与归档；Rust技能规则及Godot `skill_rules_test.tscn` 对照实际向量。`skill_battle_test.tscn`、`run_online_skills.py`、`run_skill_proficiency.py`、`run_group_skills.py`分别覆盖战斗入口、权限／回执、熟练度／重启、群攻目标与单次计数，集成脚本使用独立临时PostgreSQL，不连接玩家库。既有结果见[技能效果](../tests/skill_rebalance.md)、[熟练度](../tests/skill_proficiency.md)、[施法表现](../tests/battle_casting.md)，不把历史向量数量或一次通过当作本次重新验收。
