# 展开聊天窗口

- 底部聊天框右侧增加向上箭头，使用用户提供的 `up-2-svgrepo-com.svg` 路径并调整为主题金色；滚动条箭头复用该路径。
- `client/scenes/ui/expanded_chat_panel.tscn` 按用户明确确认的“四角带金色回纹”边框修正，不再以视频 `12_聊天页.png` 的普通直线框为目标。四角直接使用原包 `neverpic.imgs` 的第30帧：`analysis/decoded_png/ssjx/neverpic_frame030.png` → `client/assets/ui/chat_corner.png`，17×13 RGBA 像素逐点一致；上下/左右翻转组成四角，最近邻采样，未重画花纹。该纹样也可在用户视频 `11_NPC对话.png` 中确认。导入映射写入 `tools/import_assets.py`，不把原包第19帧的普通 L 形角线当作回纹。
- 暖色纸面、金色连续边线与角花连接，页签和底部说明文字向内留出空间，避免纹样盖住文字或截获点击。按用户最新要求移除弹窗底部“表情”和“返回”按钮；表情继续从原输入栏按钮进入，展开时仍可选表情并编辑同一草稿。
- 共享 `GameWorldScreen` 管理开合按钮：展开时使用同尺寸向下箭头、提示“收起聊天”，再次点击收起；Escape、外侧触摸或代码隐藏窗口后均恢复向上箭头。开合事件分别交由本地/联机控制器处理，保留输入草稿及战斗快捷键恢复逻辑。
- 支持全部、世界、系统筛选；地区、队伍、帮会、私聊保留参考图位置并禁用，提示暂未开放。发送仍使用现有公共频道协议。
- 消息来源为当前世界连接验证后的缓存；没有请求人物上线前的历史。消息与表情通过原纯文本/贴图渲染逻辑显示，任意 BBCode 不会执行。
- 翻阅旧消息时保留滚动位置；在底部时跟随新消息。窗口缓存上限100条，公共消息遵守既有服务端缓存边界，被裁剪消息不会作为新消息重新追加。
- 展开时阻止地图和战斗快捷键穿透；右下角箭头、Escape、窗口外点击或触摸均可收起。表情选择使用原输入框，发送确认后才清除草稿，网络未连接或待确认时表情入口禁用。
