# 技能接入与待恢复字段

[返回设计索引](README.md) · [NPC 入派](school-membership.md) · [组队战斗](teams.md)

性质：**当前实现规则与资料缺项**。具名技能、显式重建公式及原版未知字段分开维护；角色门派暂不限制职业技能。

用户授权接入其提供资料中的技能。运行时目录 `client/assets/data/skills-v1.json` 收录全部 **30 个具名技能**，另保留三个旧入门技能兼容已有客户端。18 条缺名称的记录仍留在 analysis，没有编造名称或原始 ID。使用 `python tools/build_skill_catalog.py` 从归档资料重新生成目录。

名称、职业／门派归属、效果文字来自 `analysis/references/player-sheet/source.csv`，每项保留行号。它是玩家提供的补充资料，不是已恢复的原服技能下发表。原生技能解析结果与证据仍见 `analysis/recovery/skills/README.md`。

## 使用方式

### 雷霆一击眩晕（2026-10-23）

力士通用技能「雷霆一击」5级解锁，保留原伤害与灵力消耗，新增命中后35%概率眩晕：跳过目标下一次行动，受击不解除，冷却3回合。与睡眠／封印共享控制保护，未命中不施加状态。眩晕按行动消费，不在回合末递减，避免后手施加时提前失效。当前首领与精英遵循相同控制保护，不新增永久免疫。

技能表以 `stun` 附加配置表达，不把该技能归入会降低伤害倍率的通用控制技能类别。它是用户授权的新玩法，不冒充原版规则。新战斗冻结 `balance.stun_revision=1`，旧在途战斗缺字段保留原行为，重连／重启不重新抽取已提交结果。正常本地、联机阵列（单人／组队）及切磋已接入，旧 `solo-v1` 协议入口保留原规则。验证与兼容细节见 [眩晕测试](../tests/stun.md)。

- 本地、联机战斗的“技能”打开同一套武功列表，显示名称、灵力消耗及效果，点击技能行或回车直接施展。增益在自身位置施展；攻击沿用已恢复的角色动作，尚无逐技能原版动画映射。
- 两种模式按 `skill-effects-v1.json` 的逐技能人工配置播放原包一次性特效，共 33 项配置、37 份 ANI；不再按职业复用同一特效。剑、雷、火、冰、治疗、屏障、催眠、毒雾及摄灵按名称／效果设计，可组合多层并分别跟随施法者或目标。物理／法术反伤心法在对应反伤事件触发。用户已授权这种语义映射，它不是原服绑定恢复成果；[逐项对应表](../analysis/recovery/skills/effect-mapping.md) 列出资源、视觉依据和触发方式。
- 特效随对象进退，但不继承角色镜像或缩放。播放完毕、对象消失、退出战斗或联机断开都会清理。进入战斗时只预备当前角色已解锁技能所需的图像与序列，不一次性加载全部特效；重新导入资源会保留映射中的 ANI。
- 本地技能在原生出招命中时开始播放对应特效及音效；角色出招动作和本次技能的全部特效层结束后，才进入怪物反击。按照特效实际生命周期等待，不追加固定停顿，不等待音频尾音；退出战斗立即取消等待，防止旧回合继续反击。技能费用、冷却与回合末持续效果仍按既有规则结算。
- 人物属性的“武功／心法”按职业展示全部已收录具名技能，不限制角色门派，标明解锁条件；自动反弹归入被动心法，不消耗行动和灵力。
- 人物技能页依照原包绘制流程，使用紧凑名称／阶数列表、独立说明与灵力区、底部技能点。原始阶数和技能点尚未恢复，显示“—”，成长入口禁用；[界面证据](../analysis/recovery/skills/interface.md) 区分原生依据与当前适配。
- 武功／心法页选中行在常态、悬浮、按下和焦点状态均保留深红底色；不再弹出遮挡列表的阶数提示。页脚显示当前等级和实际已解锁数量，说明区显示所选技能的可用等级。
- 按用户当前要求，门派暂不影响技能：峨眉／花涧／昆仑／闲云野鹤均使用本职业全部已收录技能，仍校验职业、等级、主动性和灵力。本地、联机、武功／心法页与战斗选择保持一致，页脚显示“门派不限”。50级侠客可用8项主动技能（含兼容技能），55级的万剑归宗仍锁定。技能原始门派字段保留为资料归属，不改名、不伪造缺失技能。
- `skill-reference-coverage.json` 继续保留原表18条缺名记录的可复核元数据，不改变战斗目录及其哈希；技能页不再用本门派缺项遮挡职业技能列表。缺项如下：

| 原表职业／门派 | 缺名等级 |
|---|---|
| 峨眉侠客 | 15、25、35、45、55 |
| 峨眉力士 | 25、45、55 |
| 峨眉隐者 | 35、55 |
| 花间侠客 | 35、45、55 |
| 花间隐者 | 25、55 |
| 昆仑隐者 | 25、45、55 |

- 等级列暂作为角色解锁等级，自动解锁。为让 55 级技能可达，本地、联机等级上限同步调整为 60；属性点预算保持每级 5 点，最高 300。资料没有技能阶数、升级消耗、学习 NPC 或技能点配置，不实现虚构的升级按钮。
- 新角色先以“闲云野鹤”身份出生，可通过清微道人正式入派，门派身份暂不限制技能；按用户要求，已有角色也进行一次性入派重置，等级、物品与任务保留。[入派流程与迁移](school-membership.md)。
- 原文“花间”在运行时暂对应现有“花涧”门派，analysis 原文不变。`sheet_行号` 是本项目引用 ID，不是原版 ID。

## 显式重建的数值

表内缺失消耗和公式。令 `t = (解锁等级 - 5) / 10`（向下取整），当前主动技能消耗 `9 + 3t` 灵力；有直接伤害的技能造成 `攻击 × (180 + 10t)% - 敌防御`，最低 1。支持技能无直接伤害。所有这些数值以及主动／被动分类均为可调整的重建规则，目录包含来源标记，不冒充原版。

| 效果 | 当前规则 |
|---|---|
| 流血、中毒 | 每次我方行动后，按攻击的 20% 结算；原文指定 1／2 回合，未指定则暂用 2 回合 |
| 睡眠 | 35% 概率，持续 2 回合，跳过敌方行动及动画；之后的直接攻击会唤醒 |
| 沉默 | 表内 15% 概率，暂持续 2 回合；不阻止普通攻击 |
| 回复生命 | 按最大气血的 15%，结算 2 次 |
| 防御加成 | 暂减伤 25%，持续 2 回合 |
| 暴击加成 | 暂增加 25% 暴击机会，暴击伤害 150%，持续 2 回合 |
| 主动物反／法反 | 对对应伤害类型反弹 30%，持续 2 回合 |
| 被动物反／法反 | 对对应伤害类型反弹 20%，不与同类主动反伤相加，取高值 |
| 偷取灵力 | 最多偷取 20，受敌方剩余灵力和自身最大灵力约束；临时敌方灵力池为 `30 + 等级 × 2` |

持续效果从施放回合开始结算，回合结束递减；同类效果刷新，不无限叠加。当前怪物只有物理普通攻击，没有法术 AI，法反与沉默虽已接入，但无敌方法术触发。单人遭遇只有一个敌方目标；[组队战斗](teams.md)已按 `target` 字段处理多个敌人或队友，不再把“单人单怪”当作全部战斗上限。

## 联机与兼容

双方共用版本化目录，并核对 SHA256。客户端只发送技能 ID、战斗 ID、预期回合版本和操作 UUID；服务端重新核对职业、等级、主动性和灵力，门派不参与技能权限判断，独立计算结果。拒绝的行动不扣资源、不推进回合。状态、消耗、奖励和幂等回执在同一数据库事务中提交；持续状态可随重连和进程重启恢复。旧遭遇战在有效行动时重新计算职业被动心法，保留原有持续效果；拒绝行动仍不修改状态。

旧客户端省略技能 ID 时使用三个入门技能；兼容范围限于旧客户端支持的等级，超过 50 级须更新客户端。未协商技能能力时仍走兼容入口。权限策略与目录变更需要客户端和服务端配套发布，仅更新界面不能绕过旧服务校验。基础技能迁移为 `0014`，后续入派迁移为 `0016`；部署应执行候选源码完整迁移集，不手工跳过或改写历史迁移。

## 验证

`tests/test_skill_catalog.py` 校验生成目录与归档记录；`server/tests/skills.rs` 与 Godot `skill_rules_test.tscn` 对照 33 组固定向量。`skill_battle_test.tscn` 检查本地实际战斗、菜单、联机命令与睡眠动画；`tests/run_online_skills.py` 使用独立临时 PostgreSQL 和服务实例，覆盖全部具名技能、权限、消耗、回执回放、过期回合、事务回滚、重启、持续效果与 60 级加点，不连接用户数据库。
