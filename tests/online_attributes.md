# 联网人物遮挡与属性界面

## 阶段一：树木前后遮挡

- 在线地图的树木、玩家、NPC和怪物置于同一个按落脚点Y坐标排序的节点中，取消人物固定较高Z层级。
- 地面使用场景中预置的独立TileMapLayer并固定在下层。树干原有阻挡数据保持有效，树冠区域的行走具有正确前后遮挡。
- `online_layering_test.tscn` 5项结构检查通过；真实渲染10项检查通过，包含树后和树前的重叠像素比较。人口显示13项与移动35项回归检查通过。
- 以图形模式运行，并设置 `SSJX_LAYERING_CAPTURE_PATH` 为输出目录，可生成 `tree_behind.png` 与 `tree_front.png`。
