# client/server目录划分验证记录

## 范围

- Godot工程、素材、场景、脚本、UID和Godot测试场景迁入`client/`。
- 根目录`tests/`保留Python用例、离屏辅助脚本、测试说明和验收方案。
- `server/`仅预留说明、`src/`与`migrations/`，没有Cargo工程或联网功能。
- 根目录Windows启动脚本、资源转换工具和`vmanage`已适配新路径。

## 环境

- Linux，Godot `4.7.2.stable.gentoo.ed1daf0bf`。
- 真实渲染离屏使用Xvfb与Mesa llvmpipe/OpenGL ES 3.2。
- 启动器检查使用独立`XDG_DATA_HOME`，不修改个人收藏和游玩统计。
