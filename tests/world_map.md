# 游戏内世界地图

## 本地地图界面

- 地图入口与3键打开`world_map.tscn`，采用参考图的橙金上下栏、野外/城市/门派图例、半透明场景底图、白色连线、地点名称和等级提示。
- `world_map_graph.tscn`预置79个原版图标和78条原始线段。位置、类型、等级读取已核验的Online v48总图；保留原始异常端点，不生成额外地点或场景布局。
- 左上角小地图支持鼠标点击与触摸打开世界地图；地图菜单与3键共用同一入口。每次打开自动选中玩家当前所在地图并居中，显示当前场景名与格子坐标。点击“当前位置”可从浏览位置回到当前地图。支持点击选择、鼠标/触屏拖动、滚轮及方向键浏览，图例定位对应类型，0键循环定位四个城市。
- 本地位置读取当前世界场景与角色格子，联机读取已同步地图与本人的服务端实体。总图未收录的旧场景或扩展地图只显示真实名称、坐标及“总图未标注”，隐藏其他地点的旧选择，避免误定位；不补造世界坐标。
- 本地打开时暂停行走，返回及Esc恢复同一场景。神行符数量未接入，显示“—”且禁止传送，不使用参考图中的99伪造库存。
- 本地地图21项检查通过，包含所有图标位置与原始线段逐项对比；真实渲染已检查，菜单57项回归通过。设置`SSJX_WORLD_MAP_CAPTURE_PATH`可生成截图（真实图形模式）。

## 联网共用与回归

- 联网工具栏及3键打开同一个场景，替代原先只有位置文字的弹窗。打开时取消行走，地图浏览阻止底层地图点击与方向键行走；返回保留共享地图连接和聊天草稿。
- 地图、人物属性、扩展聊天互斥；战斗期间禁止打开野外地图。地图选择与主城定位只改变浏览视野，不发送场景切换或库存变更请求。
- 地图共33项检查、真实渲染35项检查通过；完整客户端383项、菜单57项、共享界面28项、在线任务战斗28项及落点提示27项回归通过。
- 真实独立数据库任务/战斗联调通过，其中Godot客户端19项包含地图工具栏入口和返回原会话。截图为`local_world_map.png`及`online_world_map.png`。
